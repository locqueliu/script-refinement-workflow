# Calibration Examples

## 1. ORDINARY 融入最低标准

SOURCE：

```text
△Rosalie奔跑至天台边缘，一跃而起。
```

合格成品：

```text
【中景·跟拍偏加速·起跳】
【人物站位】Rosalie 从画面右侧沿楼沿向画面上方冲；前方起跳通道无遮挡，楼沿由画中部斜切至画右上，停留点交给下镜。
△Rosalie湿发在颊侧一次侧甩、下颌绷紧，呼吸自两步一吸压到一步一吸，靴底水膜在每次蹬地时溅成一道短促白扇；她奔跑至天台边缘，脚跟离地前一次深吸气，一跃而起——雨声在离地瞬间被身体的加速切开半拍。
```

动作事实不变，微表情、呼吸、重心、材质、环境声相位和落幅全部沉入 `△` 原子；镜头块只承担摄影与站位。

## 2. 叙事密度参照：连续动作链

至少应能读清以下连续链：

```text
暴雨 / 闪电 / 楼群垂直尺度
-> 主角进入方向、跨楼路径、落点与追击方路径
-> 丧尸追击反应镜 / 规模奇观
-> 起跳、半空回身、枪口后座、弹道、命中回收
-> 玻璃幕墙落幅、抹水、呼吸和尸潮揭示
-> 弃枪脱手与落幅、钢梁冲刺路径
-> 飞兽从阴影入场、翼展 / 风压 / 撞击
-> 钢梁断口、坠落路径、台词正常语速
-> 尸潮吞没、伸手余波、黑屏声音
```

不是要求每一项机械拆成一个镜头；能同镜完成就同镜，无法承担时才按 NARRATIVE REACTION SHOT 或 INFORMATION LOAD CHECK 拆分。

## 3. 人物站位成品

```text
【人物站位】Rosalie从画面中下部当前楼顶进入，身体朝画面上方下一栋楼前冲，两把微冲分别握在左右手并贴近腰侧；目标楼顶压在画面上部，楼间空隙贯穿中部，下方街谷继续延伸至画面底部。她前方不放置其他人物，后方追击区域暂留在下部纵深，使人物、落点与高度三个层次互不遮挡；本镜末从画右上冲出，下一镜由画左下弹道方向承接。
```

## 4. 场景总览与 POSITION DELTA

```text
【人物站位·本场总览】沈景辞倚画右黑车高位，沈念画左低位，破布包在她脚边；结尾沈念栽倒，沈景辞从画右抢入接住抱离。
【人物站位】沈念由画中左虚焦位置惊回，沈景辞仍在画右车边；镜头不改变轴线，只把 PRIMARY 从闪回残影收回她的脸。
【人物站位】沈景辞从画右后方一步压入画内，脚停在两人中线；沈念仍低位留在画左，车体继续作为右侧纵向锚点。
```

## 5. 失败模式

- 只写“她冲过去”“他很愤怒”：缺表演、过程与可拍身体行为；
- 只写“画面中央”“画面右侧”：缺空间分层、关系和预留；
- 只写“以视线交下一镜”：缺具体末帧 / 首帧接点；
- 只写奇观标签，不写规模、方向、层次和主体关系；
- 把所有细节放进镜头块，却让 `△` 原子仍像剧情梗概；
- HERO 很密、普通 Beat 很薄：叙事密度断层，不可交付；
- 写真人无法表演的表情：双眼发光、眼里放光、脸蛋通红、周身发光等特效化 / 卡通化表达；
- 用抽象、诗化、心象化比喻代替可执行行为（如“瞳孔里的窗光散成一片晃动的白”）；
- 擅自为 SOURCE 未标注的台词补对白 / VO / OS 标签；
- 把场景描述、△ 原子或动作说明改成人物台词或 VO；
- 英文行未说出，或擅自新增、删除、改动 SOURCE 原有标签。

## 6. 台词标注严格沿用 SOURCE

SOURCE：

```text
莱恩（VO）：七岁生日那天，我有一整面墙的乐高、一堆玩具，和一对上过头条的爸爸妈妈。
Ryan (VO): On my seventh birthday, I had a wall of Legos, a pile of toys, and a pair of parents who'd made the headlines.
妈妈：「生日快乐，宝贝。妈妈明早的飞机去谈并购，给你买了新乐高，去和卡特玩，好吗？」
Mom： "Happy birthday, sweetheart. Mom has a flight tomorrow morning for a merger deal. I got you new Legos, go play with Carter, okay?"
```

合格成品（台词文字逐字保留；只保留 SOURCE 已有的 VO 标签；英文行沿用原标签；表演提示只写在括号内）：

```text
莱恩（VO，开头自然流畅，提到爸爸妈妈时尾音略微放轻，像在等一句迟迟没有出现的回应）：七岁生日那天，我有一整面墙的乐高、一堆玩具，和一对上过头条的爸爸妈妈。
Ryan (VO, beginning naturally, then softening slightly on "parents" as if waiting for an answer that never comes): On my seventh birthday, I had a wall of Legos, a pile of toys, and a pair of parents who'd made the headlines.
妈妈（吻落下时气息很短，话紧跟着出口；说到行程时目光已经移开，最后一句才重新看向莱恩）：生日快乐，宝贝。妈妈明早的飞机去谈并购，给你买了新乐高，去和卡特玩，好吗？
Mom (breath short as the kiss lands, her words following immediately; looking away while mentioning the trip, then returning her eyes to Ryan for the final question): Happy birthday, sweetheart. Mom has a flight tomorrow morning for a merger deal. I got you new Legos, go play with Carter, okay?
```

同一句台词可按表演节拍拆到相邻镜头（文字与标点逐字不变，中英各自沿用 SOURCE 标签），拆分点之间不得插其他台词。SOURCE 未标注时不得补 VO / OS / 对白标签，也不得把场景描述转成台词。

## 7. 可表演性校准：抽象状态落到可拍行为

SOURCE：

```text
△Sherry的视线彻底模糊，缓缓失去意识。
```

不合格（抽象、诗化，真人无法表演）：

```text
△Sherry的视线彻底模糊，缓缓失去意识：她的眼睑一次比一次沉，瞳孔里的窗光散成一片晃动的白。
```

合格（事实骨架保留，全部落到真人可执行、可被拍到的行为）：

```text
△Sherry的视线彻底模糊，缓缓失去意识：她的眼睑一次比一次沉，眨眼间隔越拉越长，眼神逐渐失去焦点，头部微微前倾，扶着边缘的手指一点点滑开。
```

规则：不可控生理（瞳孔、脸色等）只写可被拍到的自然呈现；不写发光、变色、通透等只能靠后期特效呈现的夸张内容；无必要不写不易理解或无法表演的表情。

## 8. 台词括号表演提示校准

### 8.1 过短/泛化（不合格）

```text
林砚（对白，正常）：这雾不对。
林砚（对白，声线压低）：这雾不对。
```

问题：前者没有信息；后者只有声音，没有可见神态。

### 8.2 合格（常规，约 28 字）

```text
林砚（对白，声线压低，尾音收住，眉心轻蹙，眼睑压低半寸，视线钉在雾里没有移开）：这雾不对。
```

包含声音（声线压低、尾音收住）+ 可见细节（眉心、眼睑、视线），没有把动作过程塞进括号。

### 8.3 合格（情绪落点，约 39 字）

```text
林砚（对白，声线压得很低，说到“雾”字时眉心收了一下，眼睑没有抬起来，视线钉在雾里，下颌线绷着，尾音停住没有落下）：这雾不对。
```

表情绑在“雾”字的节拍上，属于这句话的说话瞬间，而不是完整动作段。

### 8.4 过长（动作段塞进括号，不合格）

```text
林砚（对白，他先蹲下，膝盖落地，手指在缆桩边缘停了一瞬，然后抹过暗红痕迹，呼吸放轻，肩背没有完全松下来）：这雾不对。
```

问题：完整动作链应写入 △；括号只保留说话瞬间的声音与可见神态。
