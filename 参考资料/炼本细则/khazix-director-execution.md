# 卡兹克 V4.10 | Narrative Density Core

> 核心最低标准以已验证的末日战场成品为准：叙事正文完整、表演自然融入、环境声有相位、站位有分层和运动路径、相邻镜头自然承接。

> 原剧本决定 WHAT；本 Skill 设计 HOW / SEE / TIME / WEIGHT / FLOW。

> 详细字段与成品例见：
> - `references/density-and-enrichment.md`
> - `references/blocking-camera-continuity.md`
> - `references/reaction-spectacle-vfx.md`
> - `references/calibration-examples.md`

## 一、最高协议 | SOURCE / INSERT

1. 完整阅读本 Skill、references 与本次 SOURCE。
2. SOURCE 是唯一事实源：人物、关系、剧情、决定、能力、伤势、道具功能、事件顺序、结果和台词锁定。
3. INSERT_ONLY 为分级锁：不改事实层与台词文字层；允许在 △ 舞台指示原子内自然融入执行细节、在原子外加入独立镜头块；台词标签只沿用 SOURCE 原文，不补全、不推断。
4. **逐字锁（分层）**：对白、VO / OS 的台词文字与标点逐字不可动；场景头、出场人物行、音效标签、SOURCE 明确镜头指令整行逐字不可动。说话标签（对白 / VO / OS）严格沿用 SOURCE，表演提示可以补充。
5. **事实锁**：△ 原子中的谁做了什么、动作顺序、决定、结果、道具状态、空间位移、关系结论不可改；文本层允许加入微表情、微动作、肢体语言、情绪、姿态余波、环境声和材质反馈。
6. **融入优先**：表演与环境类执行沉入 △ 原子；独立镜头块承担摄影、站位、反应镜、奇观、VFX、独立特写和过渡任务。
7. 不新增剧情、决定、能力、伤势、道具功能、角色、关系结论或需要后文配合的新事实。
8. 中英双语对白视为一个 CN + EN 复合原子，镜头块不得插在中间；英文行必须说出，并沿用其 SOURCE 原有标签。长台词拆分时，CN 与 EN 必须按相同语义边界拆成相同数量并严格交替 `CN1 → EN1 → CN2 → EN2`，禁止多个中文片段后集中放完整英文。
8.1. SOURCE 台词顺序是锁定关系：VO、OS、对白不得互相换位；源文 VO 在前时，成品仍须 VO 在前，镜头块不能改变台词句子之间的顺序。
9. **台词标注协议**：台词标签严格复制 SOURCE 原文；原文有标签时不得改类，原文无标签时不得新增或按语义补全。不得把场景描述、△ 原子、动作说明或环境描写改成人物台词/VO。英文标签也沿用对应 SOURCE 行的原有标签形式。中英台词如需拆分必须同步、等数量、交替输出，拆分点之间不得插其他台词。
9.1. **台词括号表演提示（标注层）**：每句台词括号内必须包含声音/气息/情绪状态与至少一个可拍的面部、眼部、下颌、喉部或手部细节；情绪落点句至少 2 个可见细节，优先写“说到某字/某句时……”的节拍变化。常规 15—30 字，关键句 25—40 字，英文 8—20 词。禁止只写“正常/平静/自然/复杂/深邃”，禁止把完整动作链、姿态余波或说完后的反应塞进括号；连续动作归 △。SOURCE 无标签时只写表演提示，不补标签。VO/OS 或角色不在画面内时，可用声音质感、气息、喉部、手部或画外动作细节替代面部细节，不得为凑可见细节让画外角色出现口型或强行入画。
10. 逐字 DELETE TEST：删除独立镜头块后，强锁内容逐字逐标点恢复。
11. 事实 DELETE TEST：删除 △ 内融入内容后，事实骨架仍可退回并完整成立；融入是扩写，不是改写。

## 三、叙事优先 | DRAMA / BUDGET

### 1. 叙事主线

整段正文以普通叙事、关系变化、观察、反应和因果为主体。HERO、PEAK、SPECTACLE 只是叙事内部强化点，不得替代叙事，也不得造成“HERO 极密、普通极薄”的断层。

无 HERO 版本必须仍连续、完整、可读。ORDINARY ≠ FLAT：普通 Beat 可以合并，但不能退化成剧情复述。

### 2. 动态预算

- TRANSITION：最小充分；
- ORDINARY：保留表演、声音、空间、动作过程的最低标准；
- RELATIONAL / OBSERVATION：针对性展开 RECEIVE、视线和关系距离；
- FIRST REVEAL：保证是什么、在哪、与谁 / 何事有关；
- HERO / PEAK：增加过程、CHANGE MOMENT、素材点和交接预算；
- AFTERMATH：保留必要姿态余波、声音余波和关系状态。

### 3. HERO 与素材点

HERO 可来自动作、能力、怪物、决定、反转、揭示、关系、情绪、力量、道德或 ICONIC。HERO 必须落到可制作素材点：启动姿态、发力链、接触、受力、结束；能力起手、蓄能、释放、轨迹、命中、衰减；怪物非人结构；非露骨关系氛围；或具体微表演 CHANGE MOMENT。

HERO 是强化点，不是全文重点的替代物；HERO 素材不与 SOURCE 台词重叠，不改写或复述台词，删除后 SOURCE 仍成立。

### 4. SPECTACLE POINT

**每场至少一个 SPECTACLE POINT。** 它是场次级爆点素材，核心是流量价值和独立成片能力，宏大规模只是可选类型。奇观可由动作、情绪、关系、道具、生物特征、声音、材质或 Blocking 形成，也可以是规模奇观；可与 HERO 重叠。

合格判定、三特征定义与限制详见 `references/reaction-spectacle-vfx.md`（该文件为唯一权威版本）。标签可写 `SPECTACLE: [奇观名]`。

## 四、叙事密度最低标准 | NARRATIVE DENSITY BASELINE / INLINE ENRICHMENT

这是所有 ORDINARY、RELATIONAL、OBSERVATION、ACTION、HERO 的最低标尺，以叙事 Beat / △ 原子为单位，不以镜头数量为单位。

### 1. 每个叙事 △ 原子必须自然融入

1. 微表情：瞳孔、眉、唇、下颌、眼睑、鼻翼、吞咽等至少一项；
2. 微动作 / 肢体语言：呼吸、视线、重心、肩背、手部、脚下、停顿或启动至少一项；
3. 情绪变化 / 姿态余波：状态从什么到什么，或呼吸未平、重心未收、手指未松、眼神未回至少一项；
4. 动作过程：进入、转折、接触 / 释放、结果、落幅中真正需要的环节；
5. 有可读环境时：环境声来源 + 与动作、呼吸、对白的先落 / 同帧 / 后落 / 压过 / 被压过关系。

这些层优先沉入 △ 原子，不堆在镜头块说明层。不能用“她很紧张”“气氛压迫”“声音清晰”“构图有层次”替代可拍行为。

**可表演性**：融入层必须是真人可执行、可被拍到的动作；禁令与正反例详见 `references/density-and-enrichment.md`（该文件为唯一权威版本）。

### 2. 每个 AI 镜头必须完成

- 一个完整可拍过程：`START → CHANGE / CONTACT → END` 中真正需要的执行点；
- 一个明确视觉组织：主体位置、9:16 上中下分层、纵向锚点或构图关系；
- 有人物叙事时，表演三层必须绑定当前动作阶段；
- 有环境时，环境声必须有来源和相位；
- 有相邻镜头时，必须有具体 FLOW；
- 有强结果、观察、揭示、对白、首次建立或世界元素时，执行对应条件触发。

### 3. 例外与反模板

纯环境、黑屏、SOURCE 已完整承担表演 / 声音的原子可例外，但例外必须由 SOURCE 本身提供。相邻 Beat 不重复“呼吸加重、雨声压入、视线交接”，除非状态或相位真实变化。

完整触发矩阵见 `references/density-and-enrichment.md`。

## 五、Blocking 与运动路径

每个 AI 镜头必须有【人物站位】。站位不是“人在画面中央”这种标签，而是主体、空间、关系和路径的可拍组织。

### 1. FULL LAYERED BLOCKING

触发：场景首镜、空间首建、跨场首镜、空间明显变化、KEY BLOCKING SHOT。

至少写三组共五项：

- 主体锚点：入画位置、面向 / 朝向 / 视线、持物 / 手脚 / 武器、9:16 高度带；
- 空间分层：画面上部、中部、下部承载元素，纵向锚点，必要光位 / 光比；
- 关系与预留：人物 / 威胁的画左画右、高低、前后、虚实，入画 / 退场 / 追击预留，谁挡谁、谁与谁对读。

若本镜发生位移，必须全部写清：

- 从哪边进入镜头：画左、画右、画上、画下、画外前景、画外背景或画内具体位置；
- 中间如何走位：方向、轨迹、经过的空间锚点、速度变化；
- 从哪边离开镜头：画左、画右、画上、画下、画外前景、画外背景，或停留在画内哪个位置作为下镜起点。

群体、追击方和对手方同时运动时分别写路径。静止镜头写停留位置。

### 2. POSITION DELTA

空间建立后，后续镜头写本镜变化、当前分层锚点、人物 / 道具 / 眼线 / 矢量关系。有位移仍写进入、走位、离开；静止写停留位置。入画方向承接上一镜出画方向，越轴 / 反向 / 跳切必须有明确动机。

完整字段、9:16 和成品示例见 `references/blocking-camera-continuity.md`。

## 六、摄影语言 | CAMERA / SHOT FLOW

### 1. CAMERA MOTIVATION

每个重要镜头回答“为什么这样看、为什么现在动 / 不动”。摄影服务跟随、揭示、注意力收放、关系距离、冲击、观察 / 反应或交接。默认：`CHARACTER / EVENT MOVES FIRST → CAMERA RESPONDS`。

### 2. 开放语汇与自由组合硬锁

**镜头、景别、运镜必须自由组合。REGISTRY 定义摄影语言的基础维度，不限制最终表达；最终镜头语言允许跨维度自由组合，组合必须增加具体执行信息。**

景别、运镜、机位、TIME、FRAME ACCENT 的母类只是判断锚点，不是白名单。组合若比基础母类多提供具体摄影 / 剪辑信息即合法，否则退回基础母类。分布检查按基础母类归类。

禁止锁死在八大类景别或固定的运镜词汇。允许"近景·横移跟拍·过肩构图"、"中景·手持摇晃·局部特写重心"、"全景·俯拍推进·空间建立"等跨维度自由命名，只要最终命名比单一母类多提供至少一项摄影 / 剪辑执行信息。

详细母类、自由组合、DIALOGUE TIME LOCK 与 FRAME 规则见 `references/blocking-camera-continuity.md`。

### 3. 9:16 与景别

人物是 PRIMARY 时，脸、眼线、身体动作、姿态、手和关键道具必须可读。环境用 TOP / MID / BOTTOM、前后纵深、门框、楼体、钢梁、楼梯、走廊和负空间建立。

特写只在局部变化成为 PRIMARY 时使用；宽景只在尺度、高度、距离、路线、包围、新威胁位置或人物与环境比例成为 PRIMARY 时重新打开。

### 4. 自然衔接 | NATURAL HANDOFF

每次剪辑必须有因：动作阶段推进、注意力转移、声音触发、空间揭示或情绪变化。上镜末帧的具体姿态、动作阶段、道具、视线、矢量或声音必须承接到下镜首帧；“交下一镜”不是接点。

## 七、动作、因果与声音

### 1. 动作过程

按需要读清：`START POSTURE → CENTER OF GRAVITY → FORCE SOURCE → DIRECTION → BODY CHAIN → CONTACT → END POSE`。一个镜头能清楚完成就保持连续。

### 2. 强结果

结果词触发 `RESULT WORD → PROCESS VALUE CHECK`。若过程有独立视觉价值、影响因果、提供新空间 / 速度 / 材质信息、是 CHANGE MOMENT 或下一反应依赖它，补 `RELEASE → TRAVEL → CONTACT → RESPONSE → RESULT`；普通 Beat 默认同镜完成。

### 3. 关键道具

维护：`WHAT → OWNER → STATE → CHANGE → NEW STATE / NEW OWNER`。脱手、落地、断裂、遗失等叙事关键状态按 NARRATIVE REACTION SHOT 判断是否需要独立画面。

### 4. 声音与材质

声音必须服务动作、切点和重量：环境、呼吸、脚步、金属、衣料、冲击、门、雨、玻璃、水膜、火焰等。材质只强化 SOURCE 已有动作的物理重量。

## 八、观察、反应、世界元素与 VFX

### 1. OBSERVATION CHAIN

人物行为依赖看见什么时：`LOOK → SEEN → RECEIVE / DECISION → NEXT ACTION`。主镜能清楚承担就同镜，不能读清才拆观察镜；动作中优先 `OBSERVE WHILE MOVING`。

### 2. REACTION RETURN CHECK

重大揭示、威胁、侮辱、冲击或信息变化后检查：`EVENT → RECEIVE → NEXT ACTION`。RECEIVE 可由面部、呼吸、停顿、重心、手部、Blocking 或下一动作承担，不机械补特写。

### 3. NARRATIVE REACTION SHOT

SOURCE 提及且承担叙事的威胁、追击方、道具状态、新入场生物、环境剧变、因果承受方必须有可读画面存在。先检查主镜能否通过前后景、遮挡、声音、反光、影子吸收；能则同镜；过载走 INFORMATION LOAD CHECK；完全无法承担且关键才独立反应镜头。

反应镜不引用台词、不新增事实，仍需完整过程、明确视觉组织和 NATURAL HANDOFF。

### 4. VFX OPPORTUNITY FLAG

主动扫描能力形态、怪物结构、已有结果的材质破坏、环境剧变、弹道 / 轨迹和时空过渡。只强化 SOURCE 已有事实，不新增能力、伤势或道具功能。详情见 `references/reaction-spectacle-vfx.md`。

### 5. 单镜三层原则

每个叙事原子必须具备三层可读性：

- ACTION：当前动作或状态变化本身；
- RECEIVE：承接方的反应、位移或状态影响；
- HANDOFF：向下一原子的具体交接矢量（姿态、视线、道具、声音或动作余波）。

允许其中一层由动作本身隐式承担（如动作结果直接暗示 RECEIVE，或自然余波完成 HANDOFF），但必须在正文中可读，不得靠观众推断补足。

先问：能否在一个连续画面内同时读清 ACTION + RECEIVE + HANDOFF？能则不拆，保持单镜。过载或 RECEIVE / HANDOFF 有独立叙事价值时才允许最小必要拆镜。

## 九、FRAME、TIME 与对白

所有 Beat 都做 FRAME 判断，但不强制特殊化。优先 `BEFORE → CHANGE MOMENT → AFTER`；一个 Beat 原则上一个主 FRAME 功能。

`VISUAL TIME ≠ DIALOGUE TIME BY DEFAULT`：对白默认正常语速、正常节奏、可读唇形；VO / OS / 旁白 / 内心独白等非现场声按「画外音口型」执行，画面中对应角色嘴巴保持闭合，不出现说话口型。画面慢动作优先放在对白前 / 后、身体局部、环境、道具或非口型主导部分，除非 SOURCE 明确指定声音时间变化。

### 台词括号表演提示（标注层）

括号只回答“这句台词怎么说”，不承担连续动作。每句必须有：声音/气息/情绪状态 + 至少一个可拍的面部或身体细节。情绪落点句优先把细节绑到台词节拍上。

合格（常规，约 28 字）：

```text
林砚（对白，声线压低，尾音收住，眉心轻蹙，眼睑压低半寸，视线钉在雾里没有移开）：这雾不对。
```

合格（情绪落点，约 39 字）：

```text
林砚（对白，声线压得很低，说到“雾”字时眉心收了一下，眼睑没有抬起来，视线钉在雾里，下颌线绷着，尾音停住没有落下）：这雾不对。
```

过长（动作段塞进括号，不合格）：

```text
林砚（对白，他先蹲下，膝盖落地，手指在缆桩边缘停了一瞬，然后抹过暗红痕迹，呼吸放轻，肩背没有完全松下来）：这雾不对。
```

## 十、亲密与安全

所有亲密内容默认 `ADULT ONLY / NON-EXPLICIT / NO NUDITY / RELATION FIRST`。自愿场景表达距离、视线、呼吸、确认、靠近、接触、释放和余波；非自愿事实表达压力、边界、失去空间、抵抗、出口和后果，不浪漫化或情色化。只有用户明确要求自愿化改编时才改写事实。

## 十一、输出协议

1. 强锁内容原样存在；△ 原子事实保留，表演 / 环境 / 情绪优先融入。
2. 镜头块格式：`【景别·摄影机状态/运动·功能】`，下一行 `【人物站位】`，随后写具体可拍执行；单镜时长上限 4 秒，需要时可在功能位标注建议时长。
3. 只输出正向的 `HOW / SEE / TIME / WEIGHT / FLOW`，不输出审计、自证、方法论解释。
4. 每场可在开头写一次【人物站位·本场总览】；之后用 POSITION DELTA，不重复静态信息。
5. 台词文字不加说明层、不改一字；标注层只沿用 SOURCE 标签，表演提示按 9.1 补充，但不得补标签、改标签或把场景描述转成台词；音效标签和场景头不加说明层、不改文字。
6. 删除所有 AI 融入内容后，强锁逐字恢复，事实骨架完整。

## 十二、QC、EXPANSION 与 ECONOMY

### 1. SHOT CHECK

每镜检查：PRIMARY、完整动作过程、明确视觉组织、表演三层、环境声相位、站位分层、运动路径、摄影动机、9:16 可读、必要 RECEIVE、强结果过程、SOURCE 指令、FRAME 功能、TIME 锁和 DELETE TEST。

### 2. PAIRWISE CHECK

相邻镜检查：`AXIS / SCREEN DIRECTION / EYELINE / POSITION / ACTION PHASE / WEIGHT / PROP / ENTRY-EXIT / VECTOR / ATTENTION HANDOFF / CAMERA ENERGY / SOUND`。

### 3. FINAL SCENE CHECK

确认 SOURCE 锁、叙事覆盖、视觉可读、连续性、输出格式、开放词汇分布、叙事密度最低标准、运动路径、自然交接、VFX 候选、反应判断，以及本场是否已有至少一个可独立成片的 SPECTACLE POINT。

### 4. EXPANSION PASS

顺序固定：先补后减。逐个 △ 原子补叙事密度；逐镜补站位与路径；补缺失的反应方、世界元素、因果过程、环境声、PERFORMANCE、FLOW 和 CHANGE MOMENT。相关层不得缺席，无关层不硬塞。

若补足后出现竞争 PRIMARY 或无法交接的独立 CHANGE MOMENT，走 INFORMATION LOAD CHECK，允许最小必要拆镜。不得修改 SOURCE 事实，不得拉长句子伪造密度。

### 5. ECONOMY PASS

只能删重复、抽象、防御和同构表达。不得删微表情、微动作、肢体语言、情绪变化、姿态余波、环境声相位、动作过程、站位路径、因果过程、RECEIVE 或 CUT HANDOFF。合并后仍必须达到 NARRATIVE DENSITY BASELINE，否则恢复融入或拆分。

## 十三、冲突优先级与硬锁

优先级：`SOURCE / SAFETY → CAUSALITY → CONTINUITY / READABILITY → CHARACTER / RELATION → INFORMATION / REACTION → DRAMA / RHYTHM → FRAME → CAMERA BEAUTY`。

硬锁：

- 不改对白、VO / OS 的台词文字与标点（说话标签只沿用 SOURCE，表演提示可补充）；不改场景头、出场人物行、音效标签、SOURCE 镜头指令任一字或标点；
- 台词括号表演提示必须含声音/气息/情绪状态 + 至少一个可拍的面部/眼部/下颌/喉部/手部细节；情绪落点句至少 2 个可见细节；不得只写泛词或把动作段塞进括号；
- 不改剧情事实、动作顺序、决定、能力、伤势、道具功能、结果或关系结论；
- 有人物叙事行为的 △ 原子不得缺微表情、微动作 / 肢体语言、情绪 / 姿态余波和动作过程；且这些表演必须真人可执行（仿真人制作）：不写双眼发光、脸蛋通红、周身发光等不可演 / 特效化表情，不用抽象、诗化、心象化比喻代替可拍行为，无必要不写不易理解或无法表演的表情描写；
- 有环境不得缺环境声来源与相位，除非 SOURCE 明确静音；
- 有位移不得缺进入方向、中间走位、离开方向；静止镜头写停留位置；
- 相邻镜出画 / 入画方向不匹配必须有明确越轴、跳切或反向动机；
- SOURCE 提及且承担叙事的世界元素不得无画面存在；
- 镜头、景别、运镜必须自由组合，不锁死在八大类或固定词汇；
- 每个叙事原子的 ACTION、RECEIVE、HANDOFF 三层必须在正文中可读（允许一层由动作隐式承担）；能单镜读清三层则不拆；
- 每场至少一个 SPECTACLE POINT（可由动作 / 情绪 / 关系 / 道具 / 生物特征 / 声音 / 材质 / Blocking / 规模形成），必须可独立成片、有启动到落幅；SPECTACLE 不新增事实；HERO 不掩盖普通叙事塌陷；
- 不用复杂运镜、特写、奇观或镜头数量伪造密度；
- 镜头、运镜与景别优先自由组合：三者均为分类锚点，不是允许词表；鼓励跨维度组合；凡组合比单一基础母类多提供一项具体执行信息（方向、速度曲线、起落、机位与主体空间关系等）即优先采用组合表达；孤立基础母类标签在有更精确的组合方式时退为次选；
- 不把表演和环境声全部堆在镜头块而让 △ 原子仍像剧情梗概；
- 不将非自愿事实改写为自愿；
- 单个镜头最长不超过 4 秒，一个镜头只承载一个可读动作过程，过长动作 / 复杂连续事件必须拆镜；不得用长时间固定镜头记录整段对白；
- 相邻镜头不得同人物 + 同景别 + 同机位 + 同构图连续重复，连续镜头须在景别 / 机位 / 角度 / 运镜 / 构图 / 节奏上至少一项变化；
- 对白场景禁止单一固定机位，须在建立镜、正反打、过肩、反应镜、手部 / 眼神细节、空间关系镜之间调度；
- 台词类型为 VO / 旁白 / 内心独白 / 非现场声时，画面中对应角色嘴巴必须保持闭合，不得出现说话口型或口型同步；
- 每场固定主光方向、冷暖与明暗关系，相邻镜头光源方向与人物受光连续；
- 规则解释只留在内部，最终只输出可拍正文。

## 最终规则

> 锁定 WHAT；叙事正文是主体，HERO / SPECTACLE 是强化点；每个叙事 △ 原子自然融入微表情、微动作 / 肢体语言、情绪 / 姿态余波、动作过程和环境声相位；每个镜头写清视觉组织、人物站位和运动路径；有位移写进入 / 走位 / 离开，静止写停留；SOURCE 世界元素必须有画面存在；镜头之间必须有具体自然交接；先 EXPANSION 后 ECONOMY；不改台词、VO / OS 文字（说话标签与表演提示属标注层，表演提示须含声音与可见细节）、剧情事实和动作结果；最终只输出具体、可拍、可执行正文。
