# Blocking, Camera and Continuity

## 1. FULL LAYERED BLOCKING

触发：场景首镜、空间首建、跨场首镜、空间明显变化、KEY BLOCKING SHOT。

【人物站位】至少交代三组、共五项以上：

- 主体锚点：画面位置、面向 / 朝向 / 视线、持物与关键身体元素、9:16 高度带；
- 空间分层：画面上部、中部、下部承载元素，纵向锚点，参与叙事的光位 / 光比；
- 关系与预留：人物 / 威胁的画左画右、高低、前后、虚实，入画 / 退场 / 追击预留，谁挡谁、谁与谁对读、人物 / 落点 / 高度是否互不遮挡。

有位移时必须写：

- 进入方向：从画左 / 画右 / 画上 / 画下 / 画外前景 / 画外背景，或已在画内的具体位置；
- 中间走位：路径、方向、速度变化、经过的空间锚点；
- 离开方向：从画左 / 画右 / 画上 / 画下 / 画外前景 / 画外背景，或停留在画内的下镜起点。

群体、追击方和对手方同时运动时分别写路径。静止镜头写停留位置。

## 2. POSITION DELTA

空间已经建立后，后续镜头写：本镜变化、当前分层锚点、人物 / 道具 / 眼线 / 矢量关系。有位移仍写进入、走位、离开；静止写停留位置。

相邻镜头入画方向承接上一镜出画方向。越轴、反向或跳切必须有动作、注意力、声音、空间或情绪动机。

## 3. 9:16 与遮挡

人物是 PRIMARY 时，脸、眼线、身体动作、姿态、手、关键道具必须可读。环境通过 TOP / MID / BOTTOM、前后纵深、门框、楼体、钢梁、楼梯、走廊和负空间建立，不用宽景替代连续性。

## 4. NATURAL HANDOFF

每次切换写清：上镜末帧的具体姿态、动作阶段、道具、视线、矢量或声音如何进入下镜首帧。“交下一镜”不是交接点。

相邻镜头保持 `AXIS / SCREEN DIRECTION / EYELINE / POSITION / ACTION PHASE / WEIGHT / PROP / ENTRY-EXIT / VECTOR / CAMERA ENERGY / SOUND`。

## 5. CAMERA MOTIVATION

每个重要镜头回答：为什么这样看，为什么现在动 / 不动。摄影服务跟随、揭示、注意力收放、关系距离、冲击、观察 / 反应或交接。默认 `CHARACTER / EVENT MOVES FIRST -> CAMERA RESPONDS`。

## 6. OPEN VOCABULARY REGISTRY

**REGISTRY 定义摄影语言的基础维度，不限制最终表达；最终镜头语言必须跨维度自由组合，组合必须增加具体执行信息。**

景别、运镜、机位、TIME、FRAME ACCENT 的母类只是判断锚点，不是白名单。允许自然组合、细分和跨维度命名。组合若比基础母类多提供一项具体摄影 / 剪辑信息即合法，否则退回基础母类。

**自由组合优先**：镜头、运镜与景别三者均不受基础母类白名单限制；有更精确的跨维度组合方式时优先采用，孤立单一词（"近景""手持""跟拍"）退为次选；有效组合须包含方向、速度曲线、起落锚点或与主体的空间关系中至少一项执行细节；分布检查仍按基础母类归类统计，不用新命名绕过单一词汇主导检查。

基础锚点：

- 景别：大远景、全景、中景、中近景、近景、特写、动作特写、大特写；
- 运镜：推、拉、横移、平移、俯拍、仰拍、旋转、POV、偷窥、跟拍、手持、滑轨、航拍、框架构图；
- 机位：低机位、高机位、平视、倾斜、旋转机位；
- TIME：慢动作、快动作、静帧；
- FRAME：静态、过渡、冲击、运动、抽帧、频闪、慢放、快切、留白。

TIME 受对白正常语速和可读唇形的 `DIALOGUE TIME LOCK` 约束。FRAME 强制判断，不强制特殊化。分布检查按基础母类归类，不允许用新命名绕过单一词汇主导检查。

## 7. CAMERA / TIME / FRAME

景别服从 PRIMARY；运动明确 `START REASON / DIRECTION / SPEED CURVE / LANDING`；镜头尺寸改变明确 `START SIZE -> MOVE -> END SIZE`；时间处理服务 CHANGE MOMENT、IMPACT、SUSPENSE、AFTERMATH 或 TRANSITION；一个 Beat 原则上一个主 FRAME 功能。

## 8. SHOT DURATION & VARIATION LOCK

- 竖屏 9:16；单个镜头最长不超过 4 秒。一个镜头只承载一个可读动作过程；过长动作、复杂连续事件必须拆镜。镜头块内不写具体秒数。
- 不得用长时间固定镜头记录整段对白；对白按表演节拍分配到建立镜、正反打、过肩、反应镜、手部 / 眼神特写。
- 相邻镜头不得同人物 + 同景别 + 同机位 + 同构图连续重复；连续镜头须在景别 / 机位 / 角度 / 运镜 / 构图 / 节奏上至少一项变化。
- 机位与运镜变化不越轴、不破坏空间关系、不改变人物站位、不出现空间跳跃或人物无故瞬移。

## 9. DIALOGUE COVERAGE

对白场景禁止单一固定机位，按情绪节点在建立镜 -> 正反打 -> 过肩 -> 反应镜 -> 手部细节 -> 眼神特写 -> 空间关系镜之间调度。禁止两人全程固定双人中景、单人讲话全程固定正脸、人物始终正对镜头。

## 10. LIGHTING CONTINUITY

每场固定主光方向、光源类型、冷暖与明暗关系；相邻镜头光源方向、光位与人物受光必须连续；光比变化须有剧情动机（如火光摇曳、云层遮月）。每场首镜写明光线设计，后续镜头写变化。
