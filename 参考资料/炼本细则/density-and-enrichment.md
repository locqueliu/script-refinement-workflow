# Density and Inline Enrichment

## 1. NARRATIVE DENSITY BASELINE

废墟战场成品的单位 Beat 浓度，是所有 ORDINARY、RELATIONAL、OBSERVATION、ACTION 与 HERO 的最低标尺。HERO 只能增加预算，不能让普通叙事退化成剧情复述。

每个具有叙事动作或人物行为的 `△` 原子，优先在原子内部自然融入：

1. 微表情：瞳孔、眉、唇、下颌、眼睑、鼻翼、吞咽；
2. 微动作 / 肢体语言：呼吸相位、视线、重心、肩背、手部、脚下、停顿或启动；
3. 情绪变化 / 姿态余波：从什么状态到什么状态，或呼吸未平、重心未收、手指未松、眼神未回；
4. 环境声：声音来源，以及与动作、呼吸、对白的先落 / 同帧 / 后落 / 压过 / 被压过关系；
5. 动作过程：进入、转折、接触 / 释放、结果、落幅中当前 Beat 真正需要的部分。

同一复合分句可以承载多层。不用“她很紧张”“气氛压迫”“声音清晰”替代具体行为。

每个原子必须达到这些信息的可读性；允许一个具体行为同时承担多层表演信息，不机械逐项补齐。

## 2. INLINE ENRICHMENT

融入优先，独立镜头块补充。

### 模式 A：融入扩写

保留 `△` 原子事实骨架，在动作词前、后或中间加入表演、环境声、材质和余波。不得新增事实、改变顺序、删除原动作或改变结果。

### 模式 B：镜头块 + 融入

镜头块承担景别、运镜、站位、VFX、SPECTACLE、FRAME、TIME；`△` 原子承担人物表演与环境执行。

### 模式 C：独立镜头块

叙事反应镜头、奇观镜头、独立局部变化特写、无 `△` 承载的过渡镜头，可独立成块。

融入不得用标签、括号或注释切割阅读；不重复镜头块已经承担的同一动作；不引用对白 / VO / OS 文本。

## 3. PERFORMANCE 最低线与设计方法

有人物承担叙事时，微表情层、微动作 / 肢体语言层、情绪 / 姿态余波层各至少一项。三层必须绑定当前动作阶段，不能随机堆模板词。

普通 Beat 也必须有表演层。纯环境、黑屏、或 SOURCE 已完整提供表演的原子可例外。

**表演设计方法**：不为表达情绪设计动作；先确定人物此刻的目标、策略、受阻与调整，让情绪从行为偏差、真实接收和关系变化中被观众读出。

**可表演性约束**：所有微表情、微动作必须真人可执行、可被摄影机拍到。禁止不可演 / 特效化表达（双眼发光、眼里放光、脸蛋通红、周身发光、冒黑气等）；不用抽象、诗化、心象化比喻代替可执行行为（如「瞳孔里的窗光散成一片晃动的白」）；视线模糊、失去意识、情绪失控等状态只能落到眼睑下沉、眨眼间隔拉长、视线失焦、头部微晃、手指滑开等可拍行为；不可控生理（瞳孔、脸色等）只写自然呈现，不做夸张化；情绪结论词不得单独出现。

## 4. AMBIENT SOUND 最低线

有可读环境时，至少写一个有来源的环境声和相位：雨、风、电流、器械、液体、远景人声、木质、金属、玻璃、水膜、火焰、布料、尘屑等。真空、意识剥离或 SOURCE 明写“静”除外。

## 5. 反模板检查

相邻 Beat 不重复“呼吸加重 / 雨声压入 / 视线交下一镜”，除非状态或相位确实变化。同一表演词不能替代不同动作阶段。

## 6. 校准标准

过薄：只复述“她跑过去”“他很生气”，没有面部、身体、情绪、声源、相位、动作落点。

合格：原事实仍清楚，但湿发、下颌、呼吸、重心、手部、视线、环境声、材质和落幅被压缩进同一段可拍叙事；镜头块只承担摄影与站位。

合格不是字数多，而是每个分句都承担一个真实制作决定。

## 7. 台词括号表演提示（标注层）

台词括号承担“这句台词怎么说”，不承担连续动作。每句至少包含：

1. 声音/气息/情绪状态：声线压低、尾音收住、气息短、喉音发紧；
2. 至少一个可拍的面部/眼部/下颌/喉部/手部细节：眉心轻蹙、眼睑压低半寸、视线钉住、下颌线绷着、喉结滚动、指节抵住桌沿。

情绪落点句至少 2 个可见细节，优先写成“说到某字/某句时……”的节拍变化。常规 15—30 字，关键句 25—40 字，英文 8—20 词。

连续动作、动作过程、情绪变化过程、姿态余波与环境声相位写入 △；括号内不写“正常/平静/自然/复杂/深邃”等泛词，不写完整动作链，也不写说完之后的反应余波。

## 8. 文化中性（强制）

- SOURCE 未建立的中国/东方文化元素、器物、服饰、礼仪、称谓、节庆、建筑与材质，不得以“表演/环境/材质”名义加入。
- 不得从中文动词反推器物：SOURCE 只写“夹菜”，不得添加筷子、筷架或“一筷之礼”；未指定餐具时写中性分菜动作。
- 需要文化细节但 SOURCE 未给时，写可拍的中性行为：点头、后退、握拳、呼吸变化、避开视线、放下手边物品。
- 文化背景锁定同样适用于 SPECTACLE 命名与镜头块，不得用文化礼仪/文化隐喻给动作“加意义”。
