# Reaction, Spectacle and VFX

## 1. NARRATIVE REACTION SHOT

处理 SOURCE 提及且承担叙事的世界元素，而非人物的 LOOK / RECEIVE：

- 威胁 / 追击方：追来、逼近、俯冲、抵达、攀爬；
- 道具状态：丢弃、摔碎、折断、遗失、转移、落地、脱手；
- 新入场角色 / 生物；
- 环境剧变：坍塌、爆炸、淹没、燃烧、断裂；
- 因果承受方：尸群、钢梁、被击中的对象等。

判定顺序：

1. 主镜能否用 Blocking、前后景、背景、遮挡、声音、反光或影子承担？能则同镜，不拆；
2. 同镜是否产生两个无法交接的 PRIMARY？走 INFORMATION LOAD CHECK；
3. 完全无法承担且元素对叙事关键，才独立反应镜头。

反应镜头仍需完整可拍过程、明确视觉组织、具体 NATURAL HANDOFF，不引用 SOURCE 台词，不新增事实。可以是弃枪落幅特写、追兵短切、尸潮俯拍、飞兽轨迹或 POV 余光。

## 2. SPECTACLE POINT

**每场至少一个 SPECTACLE POINT。** 它是场次级爆点素材：可独立传播、可形成爆点的视觉片段或素材点。流量价值和独立成片能力是核心，宏大规模只是可选类型之一，不是前提。

来源不限于规模奇观，可以是：

- 动作：瞬间反击、力量释放、极限动作；
- 情绪：一个眼神压垮对方、沉默中的关系逆转；
- 关系：保护、背叛、臣服、对峙形成的标志性画面；
- 道具：铜币、骨刀等成为整场戏的视觉核心；
- 生物特征：狐尾、兽化结构形成稀缺画面；
- 声音与材质：声音骤停、血线、碎裂、回声构成冲击；
- Blocking：人物站位本身形成权力关系或视觉反转；
- 规模奇观（可选）：无数 / 铺天盖地 / 巨大 / 极高 / 深不见底 / 暴雨 / 火海 / 飞行 / 触手 / 高楼群等，寻找堆叠、洪流、遮天、贯穿、吞没、极端垂直或极端纵深。

合格 SPECTACLE POINT 必须具备三个特征：

1. 一句话能说清卖点，例如“几个铜币压着一屋人的自由”；
2. 能独立剪成传播片段，脱离整场仍有情绪或视觉冲击；
3. 拥有清楚的启动、变化、峰值和落幅，不是单纯漂亮构图。

可与 HERO 重叠。限制：不新增剧情、能力、伤势、道具、角色、关系事实；不引用台词；只放大 SOURCE 已有事实。标签可写 `SPECTACLE: [奇观名]`。删除奇观后 SOURCE 与叙事仍完整。

## 3. HERO 素材点

HERO 是叙事内部的强化点，不是替代全文叙事的独立高地。HERO 素材点包括动作启动 / 发力 / 接触 / 受力 / 结束，能力起手 / 蓄能 / 释放 / 轨迹 / 命中 / 衰减，怪物非人结构，非露骨关系氛围，以及情绪 CHANGE MOMENT。

HERO 与普通 Beat 的表演、环境声、站位、因果和自然衔接密度不能断层。HERO 也受“对白外时间窗”约束：不引用、不改写、不复述 SOURCE 台词；删除 HERO 后 SOURCE 仍完整。

## 4. VFX OPPORTUNITY FLAG

只强化 SOURCE 已有事实：

- 能力形态、颜色、粒子、光位、环境响应；
- 翼、尾、鳞甲、复合肢、触手、异常关节；
- 金属、玻璃、混凝土、血雾、水花、尘屑等已有结果的材质反馈；
- 爆炸、坍塌、闪电、火焰、雨滴、轨迹和时空过渡。

标注可写入功能标签：`VFX: 膛口气浪 + 弹壳流`、`VFX: 翼骨压过钢梁 + 金属火花`。不得新增能力、伤势或道具功能。
