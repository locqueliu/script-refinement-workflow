# 04 · 场次覆盖与触发锚点规则

## 1. 场次覆盖（硬规则）

1. 源文每个场次必须对应「场景配乐」段中的一条 `场景名+情绪词：乐器组`；不合并、不省略、不新增。
2. 有场次号（如 `1-1`、`2-3`）时，场景名优先取源文场景行原文用词；无场次号的连续剧本按叙事段落拆 1~4 条，不编造 N-x 场次号。
3. 每场至少写 1 组乐器；较短的场可精简，但仍单独成条。
4. 一场内情绪有明显多段（如先试探后爆发）时，在该条的乐器组里用「；」内部分层或加递进词（如“先…后转…”），不拆成两个场景条目。
5. 场景名的情绪词写人物感受与戏剧张力（2~3 个），不写“很紧张”“很悲伤”这类泛词。

## 2. 触发锚点写法（「情绪音」段）

触发类型白名单：**转场、眼神特写、关键动作落点、关键台词落点**。映射组格式 `<情绪/情境>用<音效设计>`。

| 触发类型 | 示例来源 | 写法 |
|---|---|---|
| 转场 | 切场、硬切、时间跳 | 转场用金属滑音 |
| 眼神特写 | 对视、冷视、泛红 | 眼神特写用极轻心跳脉冲 |
| 动作 | 下跪、推人、砸杯、上铐 | 决断用定音鼓 |
| 台词 | “我要她”“我没事” | 宣言后重击 |
| 揭露/反转 | 身份暴露、证据出现 | 揭露用玻璃高频碎裂 |

要求：
- 映射组 2~5 组；每条对应一个可指认的触发类型。
- 音效设计具体（乐器/合成音色 + 动作），禁止空话：`高潮处加强`、`适时进入`、`配合画面`、`情绪起伏`。
- 不在「情绪音」写持续配乐；持续铺底只在「场景配乐」的乐器组里体现。

## 3. 集内结构（体现于三段文本）

- 开场：直接从本集第一个戏剧动作进入，不写“片头铺垫”，不做满编制开场。
- 推进：场景条目之间乐器组应有变化（加层/撤层/换奏法），避免整集一个音色铺到底；任何时刻不堆满编制。
- 峰值：本集最高强度点通常在中后段，用短重音（≤2 秒）表达，而非持续轰鸣；峰值后必须让位或抽空一次。
- 留白：每集至少一处近静默段落（仅环境声或单音），对白与 VO 段落去节奏化。
- 收束：每集「节奏／调性」必须写收尾策略，用未解决、硬切、渐退或主题变奏留下悬念/余韵。

## 4. 转场规则

- 同场次内换镜：节拍跟随同一动作连续移动，不为换镜重新起势。
- 场次间：用抽空→新场进入、硬切、或环境声桥接；不给每场都配独立新主题。
- 时间跳跃（如“五年后”）：可换调色/配器，但保留人物主题动机轮廓。

## 5. 正例 / 反例

- 正例：`遗迹对峙压迫：失真低音、悬停铜管；净化爆发决断：弦乐泛音、合成器空气垫、定音鼓。`
- 反例：`全程紧张刺激，配乐随剧情起伏变化。`（无场景、无乐器、无锚点）
- 正例：`对峙用铜管重击，决断用定音鼓，崩溃用玻璃高频碎裂。`
- 反例：`高潮处加强音效，适时进入紧张音乐。`
