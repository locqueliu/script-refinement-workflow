# 01 · 产出格式规范（唯一格式 · 三段式）

全剧只使用本文件规定的格式。每个集块只含四行：**标题行 + 情绪音 + 场景配乐 + 节奏／调性**，必须可以单独复制、直接用于生成该集 BGM。

## 1. 集块模板（逐字遵循）

```text
第N集｜关键词A、关键词B与关键词C
情绪音：各≤1秒，仅转场、眼神特写与关键动作/台词落点触发；<情绪/情境A>用<音效设计a>，<情绪/情境B>用<音效设计b>，<情绪/情境C>用<音效设计c>。
场景配乐：<全剧基底风格>，纯器乐。<场景1名+情绪词>：<乐器组>；<场景2名+情绪词>：<乐器组>；<场景3名+情绪词>：<乐器组>。
节奏／调性：<调性>，<BPM起点>→<中段>→<终点>BPM；<对白/动态策略>；<收尾策略>。
```

标杆示例（务必对齐其颗粒度与用词）：

```text
情绪音：各≤1秒，仅转场、眼神特写触发；诱惑用竖琴滑音，对峙用铜管重击，决断用定音鼓。
场景配乐：暗黑宫廷交响＋电子，纯器乐。夜莺宫暧昧屈辱：竖琴、低弦；王宫背叛压迫：铜管、合成低音；北境守护昂扬：圆号、弦乐、战鼓。
节奏／调性：D小调，60→80→100BPM；对白时压低，宣言后重击收尾。
```

## 2. 字段细则

### 标题行
- 固定 `第N集｜…`（全角竖线）；N 为该集集号。
- `…` 为 2~4 组关键词，用「、」连接（末组可用「与」），总长不超过 30 字。
- 关键词取自本集核心事件 / 关系转折 / 标志性场面，可中英混排；须可检索、可区分本集剧情。
- 示例：`第1集｜末世魂穿、跪地献鞭与狂化边缘`。

### 情绪音
- 领起句默认：`各≤1秒，仅转场、眼神特写与关键动作/台词落点触发；`
- 映射组 2~5 组，格式 `<情绪/情境>用<音效设计>`，用「，」分隔。
- 音效必须是一次性短音效（滑音、重击、闷击、脉冲、玻璃、心跳、锁扣、鼓点等），写具体声音设计，不写持续配乐。
- 轻点缀：只做一次性触发，不写连续打击、鼓点推进或音效叠加。
- 触发类型只允许：转场、眼神特写、关键动作落点、关键台词落点。
- 正例：`诱惑用竖琴滑音，对峙用铜管重击，决断用定音鼓。`
- 反例（禁止）：`高潮处加强音效，情绪爆发时配合画面。`

### 场景配乐
- 起头：全剧基底风格 + `，纯器乐。`；基底风格沿用 `series-bible.md` 的「风格基底」原句。
- 随后逐场列出：`<场景名+1~3 个情绪词>：<乐器组>`，条目之间用「；」分隔，末尾用「。」。
- **必须覆盖本集全部场次**：源文有几场写几条，不合并、不省略、不编造；源文无场次号时，按叙事段落拆 1~4 条（每条一个可辨识的段落/地点），不编造 N-x 场次号。
- 场景名取源文场景行或可辨识地点/事件短名；情绪词写人物感受与戏剧张力，不写“很悲伤”这类泛词。
- 乐器写具体名称与奏法/音色，如“低音单簧管暖色暗涌”“大提琴近琴桥长音”；只允许 03 技能库中的乐器，禁用清单零出现。
- 让位写法：乐器组 2~4 项为宜（低音层 + 环境层 + 点缀层）；旋律只写单音/≤4 音短动机，不写长线条大旋律与高音区歌唱性旋律。
- 正例：`夜莺宫暧昧屈辱：竖琴、低弦；王宫背叛压迫：铜管、合成低音；北境守护昂扬：圆号、弦乐、战鼓。`
- 反例（禁止）：`全剧紧张刺激，配乐随剧情起伏变化。`

### 节奏／调性
- 必含三项：① 标准调名（`D小调`、`升C小调`、`无调性`）② BPM 曲线（`60→80→100BPM` 或区间/固定值）③ 策略：对白/动态处理（如「对白时压低」）+ 收尾处理（如「宣言后重击收尾」）。
- 让位要求：BPM 以低区间为主（日常 44~90），峰值 ≤122 且短暂（≤2 秒）；必须写明对白让位策略（如“对白时压低并撤鼓”）；不得全程维持高密度强节奏。
- 可补充抽空/骤停/转调策略；用词与 02 技能表一致。
- 正例：`D小调，60→80→100BPM；对白时压低，宣言后重击收尾。`

## 3. 书写禁令

1. 不使用 Markdown 井号标题、表格、编号列表；集块内除四行外不写解释、点评与空话。
2. 不写“略”“同上”“待定”“TODO”“自行发挥”。
3. 不引用其他集事件，不写“见前文/后文/下一集”。
4. 不使用禁用词与禁用乐器（见 `global-style.md` 禁用清单）。
5. 不写人声歌词；不写需要版权采样的具体歌曲。
6. 每集块正文 100~350 字；信息密度优先，不做无意义堆叠。
7. 不得写“喧宾夺主”型处理：密集鼓点、四踩/EDM、强律动、鼓点主导、长线条大旋律、高音区歌唱性旋律、全程渐强轰鸣。

## 4. 正例 / 反例（触发锚点）

- 反例：`情绪音：转场时加入紧张音效，高潮处加强，结尾收住。`
- 正例：`情绪音：各≤1秒，仅转场、眼神特写与关键动作/台词落点触发；对峙用铜管重击，决断用定音鼓，崩溃用玻璃高频碎裂。`

- 反例：`场景配乐：紧张悬疑风格，各种乐器配合情绪变化。`
- 正例：`场景配乐：星际暗黑交响＋电子，纯器乐。污染塔对峙紧张试探：低音单簧管、悬停弦乐；净化爆发决断：弦乐泛音、合成器空气垫、定音鼓。`
