# 05 · 全剧连续性与主题动机

## 1. 先读总纲

`work/meta/series-bible.md` 由 bgm-architect 生成，包含剧名基调、**风格基底**、主要人物的主题动机命名与音色签名、全剧配乐弧线。
写作时：
- 「场景配乐」段起头的基底风格必须沿用总纲「风格基底」原句；
- 乐器与音色签名优先沿用总纲动机表（同一人物/关系在全剧使用同一组标志性音色）；
- 若在文本中提及主题名（如“女主主题”），必须与总纲/`theme-map.json` 完全一致，不得自造同义异名。

## 2. 主题动机与音色签名

- 每个主要人物/核心关系有一个主题动机；首次出现时给出动机轮廓（几个音、节奏特征）。
- 主题跨集复用时：保留动机轮廓，允许三种演化——变配器（钢琴→弦乐）、变调式（小调→大调）、变结尾（缺终音/解决）。
- 不允许：改动机音程结构、每集另起一个新主题、同一人物在不同集用完全不同音色。

示例签名（以总纲为准，此处仅作写法示范）：

| 主题 | 音色签名 | 演化方式 |
|---|---|---|
| 女主主题 | 毛毡钢琴三音下行动机 | 逐集加弦乐与低频，终章回到钢琴 |
| 男主/对手主题 | 大提琴固定音型 + 低音铜管 | 由克制到压迫；失控时加三全音 |
| 危险关系动机 | 悬停弦乐 + 心跳低频 | 由未解决到同主音大调解决 |
| 阴影/阴谋动机 | 失真摩尔斯 + 弓擦金属 | 揭晓时硬切终止 |

## 3. 全剧弧线

- 反击线：克制 → 加速 → 爆发 → 冷冽 → 终章撤离工业音色。
- 感情线：试探（未解决和弦）→ 危险亲密（心跳低频）→ 确认（同主音大调）→ 收束（自然长音）。
- 每集峰值不得连续两集压满；爆发集之后安排一次“喧嚣骤退”。

## 4. 防串集规则

1. 只写本集事实：不引用后续集事件、人物出场或身份揭示。
2. 主题名与乐器签名可跨集复用，但描述只围绕本集剧情展开。
3. 集块必须自包含：读者只拿这一块也能生成该集 BGM，不依赖前后集信息。

## 5. 对账要求

- 集块中出现的主题名必须与 `theme-map.json` 完全一致。
- 总纲未覆盖但源文确实需要的新主题：使用「人物名 + 动机」命名，并在本集 report JSON 的 `warnings` 中记录，供终检合并进总纲。
