# 02 · 情绪 → 配乐映射

写作时先在源文中定位本集主导情绪与转折点，再从下表选择风格方向、配器、速度与调性策略，最后用 01 的三段式落笔。
下表是基准库，不是唯一答案；允许组合与演化，但必须与 global-style 统一风格一致。
映射结果直接体现为：场景配乐段的「场景名+情绪词：乐器组」与节奏／调性段的「调性 + BPM 曲线 + 策略」。

## 2. 情绪音（一次性短音效）映射惯例

| 情绪/情境 | 常用音效设计（≤1 秒） |
|---|---|
| 诱惑、暧昧 | 竖琴滑音、低音单簧管气音、极轻心跳脉冲 |
| 对峙、压迫 | 铜管重击、Sub-Boom、失真低音下坠 |
| 决断、觉醒 | 定音鼓、管弦大鼓、金属重击 |
| 惊恐、失控 | 尖锐耳鸣、反向吸气、玻璃高频 |
| 揭露、反转 | 不协和簇音、弓擦镲片、锁扣“咔嗒” |
| 悬念、窥视 | 机械钟摆、颗粒噪声、极短高频泛音 |

## 3. BPM 曲线惯例

- 对峙 / 压抑：44~78，常见“近乎停滞”处理。
- 推进 / 追捕：78~100，可叠加规律电子脉冲。
- 爆发 / 反杀：100~122，节拍跟随同一动作连续移动，不为换镜重新起势。
- 告白 / 收束：60~92，随呼吸逐渐打开和声。
- 同一集内允许一条主曲线 + 局部抽空；抽空不得连续超过两次。

## 4. 调性与和声策略

- 压迫与恐惧：D / 降B / 升C / E 小调，无调性段落用于意识抽离。
- 复仇与反击：小调固定音型；兑现点转向同主音大调是常用升华手法（如 A 小调转 C 大调）。
- 关系缓和：D 小调 → D 大调、E 小调 → G 大调等“同主音/三级关系”转调。
- 悬疑收束：不落主和弦、三全音、缺失终音（主题每次循环缺最后一音）。

## 5. 转场与动态手法（写入「对白/动态策略」与「收尾策略」）

| 手法 | 用法 |
|---|---|
| 抽空 | 关键台词/动作前 1 拍撤掉打击乐，只留心跳或低频；落点后再进入 |
| 骤停 | 重大事件（坠海、爆炸、枪响后）全频骤停，仅留高频或环境声 |
| 硬切 | 场景切换不给过渡，以高压电子持续音直接切断 |
| 渐退 | 情绪退潮时逐层撤乐器，最后只剩钢琴或环境声 |
| 主题变奏 | 人物主题改配器/改调式；保留动机轮廓，只变色彩与结尾 |
| 连续冲击 | 同一动作内两次以上冲击只做力度递进，不重复完整音型 |

## 6. 选择原则

1. 一集一个声音世界：先定主导情绪簇，再定各场配器，最后写节奏／调性策略。
2. 情绪转折体现在场景条目的情绪词与乐器组变化上，不另起新主题。
3. 用词从本表与 `06-golden-examples.md` 中演化，保持全剧词汇一致。

## 7. 让位与轻量化原则（硬性）

- 情绪强度交给和声色彩、音色与低频动态，**不靠音量、音数、鼓点密度**堆出来。
- 配器一律按“低存在感”呈现：写“弦乐泛音”而非“弦乐全奏大旋律”；写“单音钢琴”而非“钢琴主题展开”。
- 旋律只允许单音与 ≤4 音短动机；每场至多一次短句呈示，不循环重复，不做高音区歌唱性旋律。
- 打击只做稀疏点缀（参考低频脉搏、单次重音、鼓刷轻扫）；不写密集鼓组、强律动、四踩（EDM）、摇滚推进。
- BPM 以低区间为主（日常 44~90）；峰值 ≤122 且短暂（≤2 秒）后立即让位；不得长时间维持 >100 的强节奏。
- 每集至少一处近静默留白（仅环境声或单音）；对白/VO 段去节奏化、撤中高频。
