# 03 · 乐器、音色与情绪音效库

## 1. 乐器 / 音色库（场景配乐「乐器组」必须取自本库）

### 管弦
- 弦乐：低音弦乐长音、大提琴（含近琴桥、滑奏、泛音）、中提琴、低音提琴、弦乐固定音型、弦乐簇音、弓擦镲片。
- 键盘/木管：毛毡钢琴、低音钢琴、预置钢琴、低音单簧管。
- 铜管：低音长号、圆号（弱奏/齐奏）、弱音小号、悬停铜管。
- 打击：定音鼓、管弦大鼓、落地通鼓、沉闷军鼓、鼓刷、颤音琴、钟琴。

### 电子 / 低频
- Sub-Bass、Sub-Boom、Sub-Drop、低频合成器、模拟合成器脉冲、失真低音、压缩心跳、反向心跳。
- 电子钟摆、颗粒噪声、白噪声铺底、无菌环境噪、合成器空气垫。

### 工业 / 拟音
- 金属敲击、钢铁撞击、工业 Impact、机械女声、锁扣、失真摩尔斯电码。

### 暗黑爵士
- 低音提琴、弱音小号、低音单簧管、鼓刷、钢琴低音区。

### 环境底噪
- 雨、海、风、船体金属呻吟、远处警笛、快门群、脚步声与衣料摩擦（采样化处理）。

## 2. 情绪音效库（一次性短音效，各 ≤1 秒）

| 音效 | 设计写法示例 |
|---|---|
| 重击 / 坠海 | 低频重击（Sub-Boom）叠加短促金属滑音；触发即发，结果前戛然而止 |
| 反击 / 利器 | 沉重冲击融合失真钢铁撞击；多次只做力度递进 |
| 枪械 | 枪械金属滑音接短促低音爆点，一拍内完成 |
| 心跳 | 极轻心跳脉冲，随逼近逐渐加密；关键台词前抽空为一次心跳 |
| 耳鸣 | 尖锐耳鸣起拍，随即混响骤停 |
| 玻璃 | 真实玻璃碎裂 + 低音冲击；碎片抵颈补一声极短高频刮擦 |
| 门锁 / 钟摆 | 机械钟摆单音定拍；门锁“咔嗒”作为唯一重音 |
| 纸张 / 屏幕 | 纸张抽出声叠加反向呼吸与冰冷玻璃泛音，控制在一秒内 |
| 打火机 / 现身 | 金属声后接反向吸气音与低音脉冲 |
| 提示音 | 清亮提示音划过（短信/设备），只做一次，不配旋律 |
| 竖琴滑音 | 上行或下行滑音，用于诱惑/暧昧转场，不重复 |
| 定音鼓 / 铜管重击 | 决断或对峙的单次重音，落点即收 |
| 电子脉冲 / 锁扣 | 科技感短点，用于设备、面板、身份揭示类触发的单次标记 |

写法要求：一个音效一个触发点；不写“持续XX音”；不堆叠同类；音效描述与触发类型（转场/眼神/动作/台词落点）对应。

## 3. 对白避让、混音与让位规格（写入「节奏／调性」策略）

- 有对白/旁白时：减少中高频旋律，保留低频脉搏、环境铺底或单音动机。
- 台词落点前后可抽空；落点后再进入，不与台词抢频段。
- 连续对白超过两轮时，音乐降为单音/底噪，只保留节奏骨架。
- VO/旁白：配乐让出中频，仅保留低频与空气感。
- 频段让位：旋律声部避开人声区（约 300Hz~4kHz）；对白时中频留白，只留低频层与环境层。
- 节奏密度：打击点缀 ≤ 每 4~8 拍一次；不写连续 8/16 分音符鼓组；低频脉冲作心跳而非节拍器。
- 峰值规格：重音 ≤2 秒，落点后立即撤层让位；不做全程渐强，不轰鸣。
- 收尾策略常用：宣言/重击后收、未解决和弦悬停、硬切留白。

## 4. 禁用与慎用

- 禁用：见 `global-style.md` 禁用清单（自动校验）。
- 慎用：甜美铃音（爱情/温情段落避免滥用）、无来源环境声、与大情绪无关的罐头音效。
- 不写人声歌词演唱；不写需要版权采样的具体流行歌曲。
