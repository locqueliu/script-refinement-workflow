# 07 · 质量规则与自检清单

## 1. Worker 交稿前自检（逐项打勾）

1. 只写四行：标题行 + 「情绪音」「场景配乐」「节奏／调性」；不写解释、点评、空行之外的内容。
2. 标题 `第N集｜关键词A、关键词B与关键词C`：集号正确；关键词 2~4 组、总长 ≤30 字。
3. 情绪音：`各≤1秒`；触发只写转场、眼神特写、关键动作/台词落点；映射组 2~5 组，格式「X用Y」；无空话。
4. 场景配乐：起头为总纲「风格基底」+「纯器乐」；覆盖源文全部场次（逐场一条）；每场有具体乐器组。
5. 节奏／调性：调名 + BPM 曲线 + 对白/动态策略 + 收尾策略，四项齐全。
6. 乐器全部来自 03 库；无禁用词、无禁用乐器、无人声歌词。
7. 只写本集事实；无“下一集/见后文”等串集引用；无占位词（略/同上/待定/自行发挥）。
8. 每集块正文 100~350 字；自包含、可直接复制。
9. report JSON 字段齐全：`{"ep":N,"status":"OK","scenes":[...],"sfx_groups":X,"cjk":Y,"warnings":[...]}`。
10. 让位检查：旋律仅单音/短动机（无长线条大旋律、无高音区歌唱性旋律）；无密集鼓点/强律动/四踩；峰值短促。
11. 对白让位策略已写明（如“对白时压低并撤鼓”）；每集至少一处留白。

## 2. QC 判卷清单

- 覆盖性：场次是否全覆盖；关键剧情节点（转折/揭露/爆发）在情绪词与乐器组中是否有对应处理。
- 锚定性：情绪音触发类型是否具体可指认；是否出现空话套话。
- 一致性：基底风格、乐器签名是否与总纲一致；词汇与技能库一致。
- 合规性：禁用词/禁用乐器、串集引用、四行结构、长度。
- 可执行性：复制该集块能否直接生成配乐（参数明确、无歧义）。
- 让位性：旋律是否克制（无大旋律主导）、节奏是否轻（无密集鼓点/强律动/四踩）、对白段是否去节奏化、是否有留白；过重即硬伤。

判定：任一硬伤即 `EPnn FAIL: 最小可执行修正要求`；无实质问题 `EPnn PASS`。

## 3. 常见失败模式（避免）

| 失败模式 | 表现 | 修正 |
|---|---|---|
| 泛化 | “紧张悬疑的配乐，逐渐推向高潮” | 落到具体情绪词、乐器、BPM、触发点 |
| 空话触发 | “高潮处加强；结尾减弱” | 写触发类型（转场/眼神/动作/台词）+ 具体音效 |
| 缺场次 | 只写 1 场，源文有 3 场 | 按源文场次逐一补齐条目 |
| 串集 | 提到后续集人物或事件 | 删除，只写本集事实 |
| 主题漂移 | 自造“复仇主旋律”等异构命名 | 统一用 bible 主题名或只写乐器签名 |
| 堆叠 | 音效重复、乐器越加越多 | 一个触发点一个音效；做减法 |
| 越界 | 出现禁用乐器/人声歌词 | 换用 03 音色库中的替代 |
| 参数缺失 | 节奏／调性缺调名或 BPM | 补全调性 + BPM 曲线 + 策略 |
| 超长/超短 | 正文 <100 字或 >350 字 | 压缩修饰词或补充场景条目 |
| 喧宾夺主 | 全程密集鼓点、大旋律铺满、对白段仍有鼓与旋律 | 撤打击、动机化旋律、对白去节奏化、补留白 |
