# 中性镜头语法 | NEUTRAL GAZE

> 模块开关：`shot-profile.json` → `gaze.active = "neutral"`。
> 默认模块；不按性别做额外偏置，只保留可执行、非客体化、情绪可读的通用规则。

## 规则

1. 镜头给最能推进信息/情绪/关系的人，不机械跟说话者。
2. 情绪落到可拍细节：眼睑、视线、呼吸、下颌、喉部、手部、重心。
3. 关系用景别、前后景、遮挡、负空间表达，不靠台词解释。
4. 不拍胸/腿/臀/唇的孤立特写，不做打量式身体扫描。
5. 情绪落点后保留 1.5–2.5 秒余波，不切在尾音上。
6. 不默认慢动作、泪眼大特写、风吹长发、柔光滤镜。
7. 9:16 构图：脸/眼在上中部，手/物件在下部，不切关节。
8. 每集至少 1 个手部/物件细节镜，用于承载情绪或关系变化。

## Plan 标记

`gaze.active=neutral` 时 `marks.gaze_beats` 可省略；若填写，类型仍使用：

`agency / micro_emotion / object / distance / aftermath / non_objectifying`

## 自检

- 情绪是否落到可拍细节？
- 是否有客体化身体镜头？
- 关系距离是否可读？
- 情绪落点是否有余波？
- 是否落入通用陈词？
