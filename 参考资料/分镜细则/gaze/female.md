# 女性向镜头语法 | FEMALE-ORIENTED GAZE

> 模块开关：`shot-profile.json` → `gaze.active = "female"`。
> 本模块只加“表达层”规则，不改契约、事实锁、台词锁、文化锁。
> 适用于以女性观众情感代入为主的女性向/女频项目。

## 一、核心原则

女性向镜头不是“把镜头拍得更柔”，也不是“慢动作+眼泪”。核心是：

1. **主体性**：她是看的人、判断的人、做决定的人，不是被打量的人。
2. **情绪颗粒度**：情绪落在“忍住—泄露—收回”的细节上，不直接演结论。
3. **关系距离**：用景别、遮挡、前后景、负空间说亲疏，而不是靠台词解释。
4. **非客体化**：镜头不消费身体；服装、妆容、光线服务人物状态，不做展示。
5. **留白与余波**：情绪落点后给 1.5–3.0 秒，让观众自己感受，不急着切走。

## 二、镜头规则

### 1. 视线归属

- 关键情绪场景由她的视线/判断组织：先给她看/她感受到，再给对象；
- 优先 POV、过肩、前景遮挡、反应切；
- 不用从上到下、从脚到头的打量式运镜；
- 男主/配角可以好看，但镜头不能只停在身体局部。

### 2. 情绪三拍：忍住 → 泄露 → 收回

每个情绪落点尽量拆成三个可见节拍：

- **忍住**：眼睑压低、呼吸放轻、手指停住、下颌收紧；
- **泄露**：喉结/鼻翼/指尖/视线出现一次失控；
- **收回**：她把情绪压回去，继续动作或说话。

示例：听到“Fated Mate”时，她叠衣服的手停住 → 指尖把衣角捏皱 → 继续叠，眼睛没有抬。

不要写：她崩溃大哭、她很绝望、她心如刀割。

### 3. 距离即关系

| 关系状态 | 镜头处理 |
|---|---|
| 亲密/信任 | 中近景、过肩、双人同框、距离压缩 |
| 疏离/背叛 | 负空间、前景遮挡、单人近景、背影 |
| 权力压迫 | 高低位、俯仰、画框/门框限制、遮挡 |
| 重新靠近 | 从前景遮挡逐步打开，或从背影转到侧脸 |

### 4. 物件与手部承载

- 每集至少 1 个手部/物件情感镜：戒指、手机、杯沿、衣角、门把手、契约印记、照片、发丝；
- 物件必须是 SOURCE 已有或场景中性物，不得新增剧情道具；
- 物件只承担情绪，不承担新因果；
- 手部动作要具体：摩挲、收紧、松开、停住、按住、收回。

### 5. 余波优先

- 情绪落点后保留 1.5–3.0 秒；
- 不切在台词尾音上；
- 用呼吸、视线、手指、环境声收；
- 余波镜可以是 P/R，也可以是场末 landing；
- 不要用慢动作伪造余波。

### 6. 非客体化

禁止：

- 胸/腿/臀/唇的孤立特写；
- 从下往上、从脚到头的身体扫描；
- 用身体局部替代人物反应；
- 把服装/妆容当作唯一信息。

允许：

- 脸、眼、手、肩背、姿态、重心；
- 服装/妆容作为人物状态的一部分（比如她重新扣好领口）；
- 亲密戏拍距离、呼吸、确认、边界和余波，不拍消费性局部。

### 7. 声音亲密感

- 呼吸、衣料、脚步、杯底、门锁、雨声近距离；
- 无 BGM；
- 用声音桥接情绪和场间；
- 关键台词前可以让环境声先落，制造“她听见了”的瞬间。

### 8. 反陈词

不默认：

- 慢动作回眸；
- 泪眼大特写；
- 风吹长发；
- 粉色柔光/雾化滤镜；
- 雨中等车、梧桐叶落等通用苦情模板（除非 SOURCE 场景已经建立）。

如果项目类型需要强情绪，可在项目配置里开 `melodrama` 子档；默认按克制写实执行。

### 9. 9:16 构图

- 脸/眼在上中部，手/物件在下部；
- 不切关节，不切半张脸；
- 负空间承担情绪；
- 双人关系用前后景/高低位，不并排站桩；
- 竖屏特写多，但每 2–3 个近景/特写要有一次景别或关系变化。

## 三、Plan 标记

在 `epNN_plan.json` 的 `marks.gaze_beats` 写：

```json
{
  "group": 3,
  "shot": 2,
  "type": "object",
  "note": "她反复摩挲杯沿，没有抬头"
}
```

类型：

| 类型 | 用途 |
|---|---|
| `agency` | 她的判断/决定/行动组织镜头 |
| `micro_emotion` | 情绪三拍、微表情、呼吸、手部 |
| `object` | 手/物件情感载体 |
| `distance` | 关系距离/遮挡/负空间 |
| `aftermath` | 情绪落点后的余波 |
| `non_objectifying` | 明确反客体化的处理 |

每集至少 3 类，至少 1 个 `object`，至少 1 个 `aftermath`。

## 四、自检

- 关键情绪场景是否由她的视线/判断组织？
- 情绪落点是否有“忍住—泄露—收回”，而不是直接演结论？
- 是否至少 1 个手部/物件情感镜？
- 关系距离是否随剧情变化？
- 情绪落点后是否有 1.5–3.0 秒余波？
- 是否有胸/腿/唇孤立特写或打量式运镜？
- 是否落入慢动作/泪眼/风吹长发/柔光等陈词？
- 9:16 构图是否可读，是否切关节？
