# 功能镜：场末落点、意象、过渡、周正机位

> 当前启用：`landing` + `image` + `transition` + `formal`。
> 成品布局为 `scene_shotlist`：marks 只写 `epNN_plan.json`，成品不显示分镜组/时长。
> `image` / `transition` / `formal` 可单独关闭：把对应数组改回 `[0,0]`。
> 所有功能镜都必须服从事实锁、台词锁、文化锁和总预算。

## 一、总预算

| 功能 | 每集数量 | 单镜时长 | 预算占用 |
|---|---:|---:|---:|
| 意象镜 | 2 必选 + 1 可选（最多 3） | 1.5–3.0s | 3–9s |
| 场间过渡 | 1–2（条件触发） | 1.0–2.0s | 2–4s |
| 周正机位 | 2–3（少量，分散使用） | 按普通镜头 | 占镜头数，不额外加时 |
| 场末收束 | 每场 1 落点；2–3 个重点场加 1 镜 | 落点 ≥2.0s；重点场 4–6s | 0–6s 净增 |
| 合计 | 5–9 镜（含重叠） | — | 5–15s |

超预算时的优先级：

```text
事实/台词/文化锁
  > 主角覆盖（P/R/N 硬指标）
  > 场末落点
  > 意象镜
  > 场间过渡
```

先砍过渡（降到 1 或 0），再砍意象（降到 2），最后才动落点；周正镜头不额外占时长，优先保留，超镜头数时先合并普通重复镜；不得删台词、硬锁或必要格式。

## 二、场末落点（landing）

### 1. 三层落点

| 层级 | 位置 | 镜头 | 时长 | 必含 |
|---|---|---|---|---|
| 剧情点/组末 | 每个分镜组最后 | 1 镜 | ≥2.0 秒 | 结果/反应/决定/余波 |
| 场末 | 每场最后 | 1–2 镜 | 重点场 4–6 秒；普通场最后 1 镜 ≥2.5 秒 | 状态变化 + 与下一场的 handoff |
| 集末 | 全剧最后 | 1 镜 | 2.5–4.0 秒 | 钩子/决定/反转，不用平静空镜 |

重点场 = 情绪转折、揭露、决定、关系变化；每集 2–3 个，不要求每场都加镜。

### 2. 怎么写

- 落点不是“多停一会儿”，而是把这一场的结果落到一个可见状态：
  - 主角反应：呼吸、视线、手指、重心、下颌；
  - 关系变化：距离、遮挡、谁先转身；
  - 动作余波：道具落点、门关上、杯子还在晃；
  - 环境回声：声音延续、光变化、空间空出来。
- 落点镜优先 P/R；不要用平静空镜收尾。
- 落点镜必须与下一场有具体 `handoff`，不能写“交下一镜”。

### 3. Handoff

| 类型 | 写法 |
|---|---|
| `sound` | 声音先入/延续：雨声、脚步、门铃、呼吸 |
| `eyeline` | 视线方向接下一场：她看向窗外 → 下一场窗外 |
| `action` | 动作匹配：她起身 → 下一场站起 |
| `object` | 道具匹配：杯子/手机/门把手 |
| `match_cut` | 构图/形状匹配：圆形灯 → 圆形钟 |

下一场第一镜必须接住 handoff。

### 4. 预算

- 每场预留 12%–18% 时长给收束段；
- 从中间冗余动作/重复反应里挪，不净加时长；
- 只有重点场额外加 1 镜；普通场只延长最后 1 镜；
- 总镜头 ≤50、总时长 ≤150 秒、总字符 ≤10000。

### 5. 与现有规则的边界

`02-craft.md` 原写“不为换镜加准备/停顿/收尾时间”，按以下口径执行：

> 收束镜必须承载状态变化/余波，不得为无信息停顿加时；余波变化属于有效的 3–5 秒变化。

## 三、意象镜（image）

### 1. 定义

以情绪/氛围外化为主要功能、用具体视觉载体承载人物内心的镜头。不是纯装饰空镜，也不是新增剧情。允许三种载体：

| `kind` | 定义 | 限制 |
|---|---|---|
| `object` | 有主体的意象：手、物件、局部动作 | 优先；不新增剧情道具 |
| `borrowed` | 借景：门窗、框、前景、倒影、水面、帘缝 | 人物可局部或不在画内；必须来自本场已建立空间 |
| `empty` | 纯空景：环境、天气、光影、人流 | 每集最多 1 个；不得连续使用 |

### 2. 规则

- 每集 **2 个必选 + 1 个可选**，最多 3 个；
- 其中至少 1 个 `object` 或 `borrowed`；`empty` 最多 1 个；
- 时长 1.5–3.0 秒，无台词；
- 只有一个微小变化：叶落、光移、车灯扫过、呼吸起雾、手指收紧、窗帘被风吹起；
- 优先“有主体的意象”：主角的手/物件、主角 POV 看到的窗/雨/街；空景/借景用于情绪停顿或场间；
- 放在情绪转折点：关键台词/反应之后、决定之前，或场末作为落点；
- 可与场末落点复用同一镜；
- 不在集首；集末只能是钩子镜。

### 3. 来源与事实锁

- 必须写 `motif`（意象物）和 `source_basis`（来自本场已建立的哪个元素）；
- 只允许场景已建立的环境元素，或中性天气/光影/人流；
- 不得新增有剧情含义的道具、文化符号、地标、服饰、礼仪；
- 不得让意象物承担新的因果关系。

### 4. 反陈词

不默认慢动作回眸、泪眼大特写、风吹长发、粉色柔光；梧桐叶落、雨中等车等模板只在 SOURCE 场景已经建立时使用。

## 四、场间过渡（transition）

### 1. 触发：跳变分

| 变化 | 分值 |
|---|---:|
| 新地点 | +2 |
| 时间跳跃（日/夜、前后时） | +2 |
| 人物组/POV 切换 | +1 |
| 事件段切换 | +1 |
| 情绪基调反转 | +1 |

- 跳变分 ≥3 且本集 ≥2 场：至少 1 个过渡；
- 跳变分 ≥5：最多 2 个；
- 单场连续戏：0–1 个，可选；
- 不要求每个场界都加，只处理“区分度较大”的场界。

边界类型（`type`）：`scene_cut` / `time_jump` / `location_change` / `event_block`。
实现手法（`technique`，可选）：`sound_bridge` / `match_cut` / `pov` / `foreground` / `empty_shot`。

### 2. 形式

- 时长 1.0–2.0 秒，无台词；
- 推荐放在新场第一镜：先用 1–2 秒过渡建立新时空，再切人物近景；
- 优先声音桥、POV、动作匹配、前景遮挡；
- 纯空镜只在新场无主角或没有更好锚点时用；
- 过渡镜尽量设计成 R（主角 POV/声音桥），保护主角比例。

## 五、周正镜头（formal）

### 1. 定义

周正镜头 = 端正、规整、低倾斜的机位。用纯正/正面、纯侧/正侧、对称/居中、平视等稳定构图，增强画面质感和电影感。它不是“所有镜头都摆正”，而是每集少量、放在合适位置的“定场/定情绪”镜头。

### 2. 类型

| `type` | 写法 | 适用 |
|---|---|---|
| `front` | 正面/纯正，机位与人物视线齐平，主体居中或左右对称 | 建立、宣告、对峙、人物肖像 |
| `profile` | 纯侧/正侧，机位在人物正侧约 90° | 关系距离、沉默、决定 |
| `symmetrical` | 对称/居中，左右平衡，垂直线明确 | 仪式、权力、空间秩序 |
| `eye_level` | 平视、低倾斜、稳定构图 | 情绪停顿、克制 |

### 3. 规则

- 每集 **2–3 个**，属于“少量”，不要每场都摆；
- 同一场不超过 2 个；不得连续堆叠；
- 至少 2 种类型（建议纯正 + 纯侧/对称）；
- 必须有 `purpose`：建立 / 仪式 / 对峙 / 决定 / 情绪停顿；
- 机位端正：平视或轻微俯仰，避免荷兰角、夸张广角、手持晃动；
- 周正镜头可以是 P/R，也可以是人景关系；不得为摆正牺牲叙事、轴线或主角比例；
- 不额外占时长；镜头数超限时先合并普通重复镜，不先砍周正镜头。

## 六、Plan marks 结构

```json
{
  "marks": {
    "landing": [
      { "scene": "1-1", "group": 1, "shots": [4], "handoff": "sound" }
    ],
    "image": [
      { "group": 2, "shot": 2, "kind": "object", "motif": "被捏皱的衣角", "source_basis": "本场已建立的衣料", "beat": "她说出分手前" },
      { "group": 5, "shot": 3, "kind": "borrowed", "motif": "门缝外的走廊灯", "source_basis": "本场已建立的门框", "beat": "他离开后" }
    ],
    "transition": [
      { "group": 5, "shot": 1, "type": "location_change", "technique": "sound_bridge", "from": "1-1", "to": "1-2", "reason": "新地点+时间跳跃" }
    ],
    "formal": [
      { "group": 1, "shot": 1, "type": "front", "purpose": "建立主角与祭坛空间" },
      { "group": 4, "shot": 2, "type": "profile", "purpose": "沉默中的决定" }
    ]
  }
}
```

约束：

- `landing`：每场一个；`shots` 用组内镜号；`handoff` 必填；重点场加 `"major": true`；
- `image`：每集 2–3 个；`kind` 为 `object`/`borrowed`/`empty`；`motif`/`source_basis` 必填；`empty` 最多 1 个；
- `transition`：`type` 在 `scene_cut/time_jump/location_change/event_block` 内；`technique` 可选；`reason` 必填；
- `formal`：每集 2–3 个；`type` 在 `front/profile/symmetrical/eye_level` 内；`purpose` 必填；同场 ≤2、不得连续。

## 七、校验

`tools/storyboard_check.py` 会调用 `tools/directing_check.py`：

- 落点：每场是否有标记、末镜时长、重点场总时长、handoff、集末钩子；
- 意象：数量 2–3、1.5–3.0s、无台词、motif/source_basis、kind、纯空景 ≤1、不在集首；
- 过渡：数量、1.0–2.0s、无台词、场界、type、reason；
- 周正：数量 2–3、类型、purpose、镜头引用、同场 ≤2、不连续；
- 计划与成稿的镜头数/顺序/时间对账。

`mode=warn` 只进警告；`mode=enforce` 进失败，接入现有 2 次返工预算。

## 八、自检

- 每个分镜组末镜是否承担落点功能？
- 每场末镜是否 ≥2.5 秒？重点场收束是否 4–6 秒？
- 是否每场都有 `landing` 标记和具体 `handoff`？
- 意象镜是否有 2–3 个、`kind` 是否合理、`motif/source_basis` 是否来自本场已建立元素？纯空景是否 ≤1？
- 过渡镜是否在场界、是否无台词、是否优先 R？
- 周正镜头是否有 2–3 个、类型是否至少 2 种、是否同场 ≤2 且不连续？
- 加完功能镜后，总镜头/时长/字符是否仍在 28–50 / ≤150s / ≤10000？
