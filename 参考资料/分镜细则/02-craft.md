# 分镜写稿细则（空间、表演、镜头、声音）

## 一、空间与多人关系

- 每个场景先选移动最少、最稳定的人物作参照，用固定物品（门、桌、柜台、台阶、柱子）锁定真实站点；其他人写相对方位、前后偏差、间距、身体朝向、视线目标。
- 每组 `空间起点` 必须独立写全：谁在画左/画右、谁在前/中/后景、谁高/谁低、相距多远、朝向谁、与哪个参照物什么关系、摄影机在哪一侧。
- 禁止“同上、同前、位置不变、承接上一组、参照上组”。
- 走位写清：从哪进、经过哪、停在哪、朝哪转；走位后重新核对全员关系；未动者保留原站点。
- 双人对话固定关系轴；过肩/反打继承画面左右与轴线，不越轴。
- 三人以上写清三角/前后/高低关系；后入场先给声音、入口或移动方向；同场人物不得无故消失。
- 关键动作链：接触前起点、发力/接触、结果、双方反应；不得用切镜跳过接触，不得用结果替代动作。
- 道具写清持有者、支撑面、取放过程、落点；关键道具断裂/脱手/换手要可见。

## 二、表演

- 写实主义 + 心理现实主义；情绪由刺激、判断、行动推进，不直接写“愤怒/紧张/绝望”。
- 每句台词括号只写“怎么说”：声音/气息/情绪状态 + 至少一个可拍的面部、眼部、下颌、喉部或手部细节；不把完整动作链塞进括号。
- 说话者出镜：写可见动作/神态/语气；说话者未出镜：标 OS/VO/电话画外音，只写可听见的呼吸、停顿、语速、语气，不虚构画外表情。
- 倾听者：在信息抵达时给符合心理的视线、神态、动作或距离变化；普通反应并入对白/关系镜，不逐人补无功能反应镜。
- 抽象状态（平静/冷静/冷酷/克制/淡漠/沉默）必须转成可见表演；不能面无表情。
- 颜色只在剧情需要时写；不写“脸色惨白/通红/眼睛发光”等；禁止孤立嘴唇、牙齿、鼻子、眼睛大特写。
- 开头/结尾优先近景或特写；禁止普通全景/空镜开场收尾（转场空镜只用于场间）。

## 三、镜头

- 每镜一个完整可拍过程（起—变/接触—落），单镜 ≤4 秒。
- 相邻镜不得同主体 + 相近景别 + 同构图；需要同景别时合并或换主体/关系/道具。
- 景别：冲突、羞辱、认知改变、关系转折、证据、爆发优先近景/特写；中景用于双人关系/移动/关键动作；全景只用于空间建立/大范围移动。
- 镜头给最能推进信息/情绪/关系的人，不机械跟说话者；长台词可在说话者、倾听者、关系画面、道具之间调度。
- 每镜技术描述写景别、机位/高度/俯仰、固定或运镜；有焦段则写；不写象征意义/观众感受。
- `画面范围` 写实际入画人物、景深、正/侧/背、可见身体范围、遮挡；`画外锁定` 只锁不该入画的人/部位。
- 每 3—5 秒至少一次有效变化；不为换镜加准备/停顿/收尾时间。

## 四、声音

- 每场建立 1—3 种代表性环境声；组末 `声音设计` 汇总本组实际可听的声音。
- 声音开始/停止/影响表演时，在对应镜头动作段写触发时点，不只留组末。
- 无 BGM、无字幕、无画面新增文字；台词不生成字幕。

## 五、台词

- 逐字锁定；不翻译、不改写、不增删、不调序、不改角色归属。
- 长台词按标点/语义拆到连续镜头，每片只出现一次；极短回应不拆。
- 标签只用 `对白 / VO / OS`；源 `O.S.` 归一为 OS；源无标签不补。
- 双语 profile 保留中英对照；英文为表演/计时轨，中文为对照。

## 六、交付自检

- 组首空间起点可独立还原全组；组末声音/禁止齐全。
- 时间轴连续、求和等于组时长；组 ≤15s、集 ≤150s、单镜 ≤4s。
- 台词拼回原文；无漏句/多句/改字；标签无未授权改动。
- 无 `△`、`SPECTACLE`、`VFX`、`[EN]:`、`【人物站位】`、`【景别`。
