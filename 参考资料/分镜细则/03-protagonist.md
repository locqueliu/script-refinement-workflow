# 主角镜头贯穿与镜头规划（2.0 分镜版）

> 规则来源：1.0 `main` 分支 `参考资料/炼本细则/protagonist-shot-design.md`。
> 2.0 适配：P/R/N 写入 `work/storyboard/epNN_plan.json`，成品正文不写标记；比例由 `tools/storyboard_check.py` 统计。
> 配置：根目录 `shot-profile.json`。

## 一、适用范围

- 只处理已进入 `/炼剧本` 的集；整集无主角或主角戏份极少的集，由 `/前置检查` 的主角覆盖检查标记，不在本规则内硬加。
- 主角来源：`work/meta/protagonist.json`（默认单主角，自动识别；`shot-profile.json` 的 `protagonist.names` 可人工覆盖）。
- 不得新增 SOURCE 未建立的主角在场、能力、关系、道具或事件。

## 二、三类镜头

| 类型 | 定义 | 是否计入主角关联 |
|---|---|---|
| **P｜主角镜** | 主体就是主角：脸、眼、身体、动作、决定、POV、手部插入、主角反应 | 是 |
| **R｜主角关系镜** | 主体是配角/环境/道具，但通过合法关系锚定到主角 | 是 |
| **N｜非主角镜** | 与主角没有视线、因果、声音关联 | 否 |

### R 的合法子类型

| 子类型 | 锚点 | 示例 |
|---|---|---|
| `pov` | 主角主观视点 | 主角看向门口，切门口的人 |
| `ots` | 过肩/前景带主角 | 主角肩后拍对面配角 |
| `foreground` | 主角在前景（虚焦/局部） | 主角侧脸虚焦在前景，焦点在配角 |
| `frame` | 主角通过门框/窗框/缝隙观察 | 门缝里主角的眼睛，画外是配角 |
| `observe` | 主角在画内观察，且观察本身是叙事 | 主角在车窗外看着，焦点在远处 |
| `object` | 主角的手/物件进入画面并承担信息 | 主角指节压在柜台上；主角手里的照片 |
| `hand` | 主角手部细节 | 主角手指收紧、松开、敲击 |
| `voice` | 主角 VO/OS 覆盖画面 | 主角旁白覆盖配角画面 |
| `reaction` | 配角动作/台词落在主角反应上 | 配角说完，切主角下颌绷紧 |
| `cause` | 配角镜头是主角上一动作的直接结果 | 主角推门 → 配角回头 |
| `sound` | 主角画外声音触发画面 | 主角脚步/呼吸/敲击先入，下一镜揭示主角 |
| `reflection` | 主角倒影/反光 | 玻璃里主角的倒影 |
| `shadow` | 主角影子入画 | 主角影子先落在墙上 |

## 三、比例指标

默认值见 `shot-profile.json`；`mode=warn` 只报告，`mode=enforce` 硬阻断。

| 指标 | 硬底线 | 目标 |
|---|---:|---:|
| `(P+R)/total` 主角关联镜占比 | ≥70% | 80%–85% |
| `P/total` 主角本人镜占比 | ≥35% | 40% |
| `N/total` 非主角镜占比 | ≤30% | ≤20% |
| 连续 N 镜 | ≤2 | ≤1 |
| 连续配角互动 N 镜 | ≤2 | ≤1 |
| 有主角在场场次的主角关联镜 | ≥1 | ≥2 |
| 主角特写占全部特写 | ≥30% | 40% |
| 关联点类型数 | ≥3 | ≥4 |
| `R-OBSERVE` 占关联镜 | ≤30% | ≤20% |

2.0 追加 warning（不单独阻断）：

- `(P+R)` 屏幕时间占比 ≥65%，`P` 屏幕时间占比 ≥30%；
- 每集第一次 P 镜尽量落在前 2 镜内；
- 有主角在场的场次，末镜优先给主角反应/决定；
- 集末钩子镜优先 P；
- 9:16 构图下，主角的脸/眼/手在上中区可读，不切关节。

## 四、规划步骤（先规划后写稿）

1. **读主角**：读 `work/meta/protagonist.json`，确认唯一主角与别名。
2. **读场次地图**：读 `work/preflight/protagonist.json` 中本集 `scene_map`，确认每场主角是否在场。
3. **写每场贯穿线**：主角这场要什么 → 遇到什么阻力 → 做了什么决定 → 状态变成什么。
4. **先排 P**：首次揭示、决定、动作结果、情绪落点优先给主角本人。
5. **再排 R**：配角互动段选合法锚点；每个配角互动段至少一个 R。
6. **最后排 N**：环境、奇观、纯配角段；连续不超过 2 镜，并尽快切回 P/R。
7. **功能镜预算**：先留场末落点；意象/过渡在配置开启时再留（见 `04-directing-marks.md`）。
8. **自检比例**：不达标先改规划，不靠正文硬塞。
9. **按规划写正文**：每个镜头的 `relation`/`anchor` 只写在 plan，不写进成品正文。

## 五、2.0 格式落点

`work/storyboard/epNN_plan.json` 每个镜头增加：

```json
{
  "no": 1,
  "relation": "P",
  "anchor": "hand",
  "subject": "Nora",
  "subject_type": "protagonist",
  "purpose": "她说出分手前的最后一次犹豫"
}
```

约束：

- `relation`：`P` / `R` / `N`；
- `subject_type`：`protagonist` / `support` / `environment` / `prop` / `spectacle`；
- `anchor`：P 用 `face/eyes/body/action/hand/pov/voice/reaction/decision`；R 用上表子类型；N 用 `none`；
- `shots` 数量必须等于成稿镜头块数量，顺序一致；
- planner 可在 plan 的 `directing` 段写自检统计（可选，checker 会重算）。

## 六、场景 playbook

| 场景类型 | 规划策略 |
|---|---|
| 主角独处 | P 为主；环境镜用 POV / 手部插入 / 主角观察 |
| 双人对白（主角+配角） | 正反打；配角说话连续不超过 2 镜；情绪落点切主角反应；过肩/前景做关系 |
| 配角对白（主角在场） | 主角作为观察者/被谈论者；用 OTS、前景、反应切、手部插入；每 2 镜回主角 |
| 群像/多人 | 主角是视觉锚点；前景/背景分层、焦点转移、视线关系 |
| 动作/奇观 | 主角在因果链里（做、承受、反应）；纯奇观 N 镜不超过 2，切回主角反应/决定 |
| 反派独场 | 用主角 POV/监听/事后发现；若 SOURCE 无主角，按 N 计入比例，不硬加 |
| 过渡/蒙太奇 | 主角 VO/OS、主角物件、主角移动方向；否则 N，但受连续段限制 |

## 七、2.0 的双主角预留

- `shot-profile.json` 的 `protagonist.mode` 默认 `single`，与 1.0 完全同阈值。
- 女频 CP 项目可设 `dual`，并在 `protagonist.names` 写两位主角；`dual` 的 P1/P2 分配和统计规则在后续版本实现，当前先按 `single` 运行。
- 不要在没有配置的情况下把配角自动当第二主角。

## 八、禁止事项

- 不得在 SOURCE 没有主角在场的场次硬加主角。
- 不得让主角站在背景里，没有动作、决定、反应（主角墙纸）。
- 不得为凑比例破坏 180 度轴线、空间关系、站位连续性。
- 不得把配角变成纯反应道具；配角仍要有自己的 ACTION / RECEIVE / HANDOFF。
- 不得因为台词里提到主角名字，就把镜头标成 R。
- 不得每句台词都切主角特写；镜头跟情绪节拍，不机械交替。
- 不得为比例牺牲 SPECTACLE、建立镜或动作过程。

## 九、自检

- 主角关联镜是否 ≥70%？主角本人镜是否 ≥35%？纯 N 是否 ≤30%？
- 是否有连续 3 个以上 N 镜？是否有连续 3 个以上配角互动 N 镜？
- 有主角在场的场次是否都有至少 1 个 P/R？
- 是否有“主角站在背景里”的墙纸镜头？
- 关联点是否至少有 3 种？`observe` 是否过多？
- 是否新增了 SOURCE 没有的主角在场、能力、关系或事件？
- 删除所有镜头块后，SOURCE 事实与台词是否仍完整？
