# 竖屏分镜稿输出契约（目标 A/B 共用）

本文件是 `/分镜` 的唯一交付标准。默认 profile 为 `B_bilingual_full`，可在根目录 `storyboard-profile.json` 切换为 `A_english_lean`。

## 一、固定结构

```text
第N集
N-N 日/夜 内/外 场景名
人物：角色A、角色B
分镜1（时长：12.0秒）
空间起点：本组 0.0 秒仍在场的全部人物位置、朝向、距离、场景参照物；摄影机位置与拍摄方向
镜头1（0.0—3.0秒）
景别，机位/运镜。（姿态：…）（位置：…）本镜动作、表演、画面范围
角色（表演提示）：台词
镜头2（3.0—6.0秒）
...
声音设计：本组实际可听的环境声、动作声、人声
禁止：无背景音乐，无字幕。
```

- 集标题：`第N集`。
- 场次行：`N-N 日/夜 内/外 场景名`；字段顺序可按源稿，但必须含场号、时间、内外、地点。
- 人物行：`人物：` 或 `出场人物：`，列本场实际出镜/发声人物。
- 分镜组：`分镜N（时长：X.X秒）`；同集从 1 连续编号。
- 镜头：`镜头N（A.A—B.B秒）`；组内从 0.0 开始，首尾相接。
- 组首必须有且只有一个 `空间起点：`。
- 组末必须有 `声音设计：`（或 `声音：`）与 `禁止：`（或 `硬性禁止：`）。
- `画面范围：`、`画外锁定（禁止生成入画）：` 为可选字段（B 常用，A 可省略）。
- `【…】` 只能作为镜头语言/动作标签，不得写成 `【人物站位】`、`【景别…】` 等旧字段。

## 二、硬指标

| 指标 | 上限/范围 |
|---|---|
| 单镜时长 | ≤4.0 秒 |
| 分镜组时长 | ≤15.0 秒 |
| 单集时长 | ≤150.0 秒（**上限，不是目标**；短集 80—120 秒即可） |
| 分镜组/集 | 6—12（不要为凑数分组） |
| 镜头/集 | 28—50（不要为凑数切镜） |
| 中文/集 | 4500—7000 字（目标 B 约 5200，超出需压缩） |
| 时间精度 | 0.5 秒；小数只用 .0/.5 更佳 |
| 组内时间轴 | 从 0.0 连续，镜头时长之和 = 组时长 |
| 贴近上限提醒 | 单集 >145 秒需确认是否必要 |

## 三、禁用

- 禁用 `△`、`SPECTACLE`、`VFX`、`【人物站位】`、`【景别`、`[EN]:`。
- 禁用 `同上`、`同前`、`承接上一`、`位置不变`、`参照上组` 等空间省略词。
- 禁用无来源的新人物、新剧情、新能力、新伤势、新道具功能。
- 禁止 BGM、字幕、画面新增文字。

## 四、语言 profile

### B_bilingual_full（默认）

- 保留源稿中英双语台词；英文是表演/口型/计时轨，中文是对照。
- 英文逐字保留；中文按同一语义边界拆分。
- 标签支持 `对白 / VO / OS / O.S.`；`O.S.` 统一按 OS 处理。
- 目标 B 的 `画面范围` 可选但建议写。

### A_english_lean

- 最终只保留英文台词；中文译文删除（不是改写）。
- 英文逐字保留；可按语义拆到多镜。
- 中文只保留在表演提示/动作说明中。

## 五、台词规则

- 每句源台词必须在成品中出现且只出现一次（长台词拆分后各片段只出现一次，拼起来等于原文）。
- 不新增、不改写、不翻译、不合并角色归属。
- 标签只沿用源稿；源稿无标签时不得擅自补 `对白`，除非 profile 明确允许。
- 长台词拆分优先在标点/语义边界；极短回应（No. / 滚。）不拆。
- 拆出的片段可以分给说话者、倾听者反应或关系画面。

## 六、质量目标

- 每个分镜组可独立生成：只读本组 `空间起点` 就能还原人物位置与摄影机关系。
- 每 3—5 秒至少一次有效变化（信息、动作结果、关系、情绪、证据、反转）。
- 多人镜头写清高低位、前后纵深、左右、遮挡、视线与轴线。
- 关键动作链写清触发—动作—接触—结果/反应。
- 倾听者有符合心理的可见反应，不呆滞陪站。
- 开头/结尾优先近景或特写；禁止孤立器官大特写。
- 每集 30—45 镜、约 4800—5200 中文字，按目标稿密度执行；不为凑数加空镜。
