# 竖屏分镜稿输出契约（目标 A/B 共用）

本文件是 `/炼剧本` 竖屏分镜稿的唯一交付标准。默认 profile 为 `B_bilingual_full`，可在根目录 `storyboard-profile.json` 切换为 `A_english_lean`。

## 一、固定结构

```text
第N集
N-N 日/夜 内/外 场景名
人物：角色A、角色B
空间起点：本场 0.0 秒全部在场人物位置、朝向、距离、场景参照物；摄影机位置与拍摄方向
镜头1
景别，机位/运镜。（姿态：…）（位置：…）本镜动作、表演、画面范围
角色（表演提示）：台词
镜头2
...
声音设计：本场实际可听的环境声、动作声、人声
禁止：无背景音乐，无字幕。
```

- 集标题：`第N集`。
- 场次行：`N-N 日/夜 内/外 场景名`；字段顺序可按源稿，但必须含场号、时间、内外、地点。
- 人物行：`人物：` 或 `出场人物：`，列本场实际出镜/发声人物。
- 场首必须有且只有一个 `空间起点：`；本场所有镜头共用这一空间起点。
- 镜头：`镜头N`，只写镜号，**不带时长**；每场从 1 连续编号。
- 场末必须有 `声音设计：`（或 `声音：`）与 `禁止：`（或 `硬性禁止：`）。
- 不再输出 `分镜N` / `分镜时长` / `镜头时间轴`；内部 `epNN_plan.json` 仍保留组与时长用于节奏控制，成品不显示。
- `画面范围：`、`画外锁定（禁止生成入画）：` 为可选字段（B 常用，A 可省略）。
- `【…】` 只能作为镜头语言/动作标签，不得写成 `【人物站位】`、`【景别…】` 等旧字段。

## 二、硬指标

| 指标 | 上限/范围 |
|---|---|
| 镜头/集 | 28—50（不要为凑数切镜） |
| 中文/集 | 4500—9000 字为目标（目标 B 约 5200）；超过 9000 仅提示，不作为失败条件 |
| 总字符数/集 | **仅 >10000 为硬错误**（含所有标点、空格、换行）；≤9000 为目标提示，9001—10000 可通过，不因长度单独返工 |
| 内部计划单镜/组/集时长 | ≤4.0s / ≤15.0s / ≤150.0s；只用于 plan 与节奏校验，**不写进成品** |
| 内部计划组/集 | 6—12（只用于 plan 结构，不写进成品） |
| 内部时间精度 | 0.5 秒；只用于 plan |
| 单集 >145 秒 | 内部计划需确认是否必要；成品不显示 |

## 三、禁用

- 禁用 `△`、`SPECTACLE`、`VFX`、`【人物站位】`、`【景别`、`[EN]:`。
- 禁用 `同上`、`同前`、`承接上一`、`位置不变`、`参照上组` 等空间省略词。
- 禁用无来源的新人物、新剧情、新能力、新伤势、新道具功能。
- 禁止 BGM、字幕、画面新增文字。

## 四、语言 profile

### B_bilingual_full（默认）

- 保留源稿中英双语台词；英文是表演/口型/计时轨，中文是对照。
- 英文逐字保留；中文按同一语义边界拆分。
- 标签支持 `对白 / VO / OS / O.S.`；`O.S.` 统一按 OS 处理。
- 目标 B 的 `画面范围` 可选但建议写。

### A_english_lean

- 最终只保留英文台词；中文译文删除（不是改写）。
- 英文逐字保留；可按语义拆到多镜。
- 中文只保留在表演提示/动作说明中。

## 五、台词规则

- 每句源台词必须在成品中出现且只出现一次（长台词拆分后各片段只出现一次，拼起来等于原文）。
- 不新增、不改写、不翻译、不合并角色归属。
- 标签只沿用源稿；源稿无标签时不得擅自补 `对白`，除非 profile 明确允许。
- 长台词拆分优先在标点/语义边界；极短回应（No. / 滚。）不拆。
- 拆出的片段可以分给说话者、倾听者反应或关系画面。

## 六、质量目标

- 每个场次可独立生成：只读本场 `空间起点` 就能还原人物位置与摄影机关系。
- 每 3—5 秒至少一次有效变化（信息、动作结果、关系、情绪、证据、反转）；按内部 plan 时间执行，成品不写秒数。
- 多人镜头写清高低位、前后纵深、左右、遮挡、视线与轴线。
- 关键动作链写清触发—动作—接触—结果/反应。
- 倾听者有符合心理的可见反应，不呆滞陪站。
- 开头/结尾优先近景或特写；禁止孤立器官大特写。
- 每个场次末镜必须承担落点功能（结果/反应/决定/余波）；场末落点时长由 plan 控制（普通场末镜 ≥2.5 秒、重点场 4—6 秒、集末 2.5—4.0 秒），成品不写秒数。
- 场间转场镜可作为新场首镜；意象镜/过渡镜是按功能计算的镜头，不得当普通空镜凑数。
- 每集 28—50 镜、约 4500—9000 中文字（目标 B 约 5200），按目标稿密度执行；不为凑数加空镜。
- 每集规划 2—3 个周正机位镜头（纯正/纯侧/对称/平视），少量分散，用于建立、仪式、对峙、决定或情绪停顿。
- 每集规划 2—3 个意象镜（`object`/`borrowed`/`empty`），其中纯空景 `empty` 最多 1 个；意象镜不得脱离本场已建立空间。
