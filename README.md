# 炼剧本工作流

把一份分集剧本 `.docx` 依次炼成：

1. **优化存档**：修复剧情问题、统一格式、逐字锁定台词
2. **导演执行稿**：逐集富化为可拍的导演执行稿（Word）
3. **配乐方案**：逐集生成四行三段式 BGM 提示词（Word）

## 快速开始

1. 安装 Python 3.10+、`python-docx` 与 OpenCode V2。
2. 把**一个**剧本 `.docx` 放入 `剧本输入/`。
3. 依次运行：
   - `/前置检查`
   - `/炼剧本`
   - `/配乐`

详细流程、产物路径与常见问题见 [操作文档.md](操作文档.md)。

## 目录

| 路径 | 说明 |
|---|---|
| `.opencode/commands/` | 三个工作流命令 |
| `.opencode/agents/` | 质检、优化、炼本、配乐 agent |
| `tools/` | 0-token 校验、合并、回写、导出脚本 |
| `参考资料/` | 炼本细则、审查优化规则、配乐规则 |
| `剧本输入/` | 源剧本入口 |
| `work/` | 中间产物（运行时生成，已忽略） |
| `output/` | 最终成品（运行时生成，已忽略） |
| `global-style.md` | 炼稿全局制作规格 |
| `标准格式执行标准与示例.md` | 源剧本交付规范与成品校验标准 |

## 环境

```powershell
python -m pip install python-docx
opencode --version
```

建议使用 OpenCode V2，并在修改 `.opencode/` 配置后重启或新开会话。
