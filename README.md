# 炼剧本工作流

> **当前分支：`v2.0-yanyi-workflow`（2.0 演绎剧炼本工作流）**  
> **稳定基线：`main`（1.0 解说剧炼本工作流）**

## 版本分支

| 版本 | 分支 | 面向 |
|---|---|---|
| 1.0 解说剧炼本工作流 | `main` | 解说剧 |
| 2.0 演绎剧炼本工作流 | `v2.0-yanyi-workflow` | 演绎剧 |

版本定位、差异与维护方式见 [版本说明.md](版本说明.md)。

> 2.0 已加入文化背景硬锁：不得添加 SOURCE 未建立的中式元素、背景、器物、礼仪、称谓；不得从“夹/端/递”等中文动词反推筷子、筷架等器物。前置质检已加入 `culture-profile.json` + 0-token 文化扫描。

把一份分集剧本 `.docx` 依次炼成：

1. **优化存档**：修复剧情问题、统一格式、逐字锁定台词
2. **竖屏分镜稿**：`/炼剧本` 按目标 A/B 模板生成“分镜组—镜头—时间轴—空间起点”分镜稿（Word）
3. **配乐方案**：逐集生成四行三段式 BGM 提示词（Word）
4. **台词核对**：逐句核对原文台词与对白/VO/OS 标签是否被改动（写入 `work/report/dialogue_audit.json`，不单独出文件）

## 快速开始

1. 安装 Python 3.10+、`python-docx` 与 OpenCode V2（已验证 CLI `v2.0.32` / service `2.1.4`）。
2. 把**一个**剧本 `.docx` 放入 `剧本输入/`。
3. 依次运行：
   - `/前置检查`
   - `/炼剧本`（竖屏分镜稿）
   - `/配乐`

详细流程、产物路径与常见问题见 [操作文档.md](操作文档.md)。

## 目录

| 路径 | 说明 |
|---|---|
| `.opencode/commands/` | 三个工作流命令 |
| `.opencode/agents/` | 质检、优化、炼本、分镜计划/写稿、配乐 agent |
| `tools/` | 0-token 校验、合并、回写、导出脚本 |
| `参考资料/` | 炼本细则、分镜细则、审查优化规则、配乐规则 |
| `剧本输入/` | 源剧本入口 |
| `work/` | 中间产物（运行时生成，已忽略） |
| `output/` | 最终成品（运行时生成，已忽略） |
| `global-style.md` | 炼稿全局制作规格 |
| `标准格式执行标准与示例.md` | 源剧本交付规范与成品校验标准 |
| `culture-profile.json` | 文化背景/目标市场配置 |
| `storyboard-profile.json` | 竖屏分镜 profile（A 英文轻量 / B 双语完整） |

## 环境

```powershell
python -m pip install python-docx
opencode --version
```

建议使用 OpenCode V2；修改 `.opencode/` 配置后 V2 会自动热重载，必要时执行 `/reload` 或新开会话。
