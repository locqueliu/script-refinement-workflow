# 版本说明 / Release Notes

## v1.1.0 — 2026-10-24

### 中文

本版本在 1.0 解说剧炼本工作流上增加两项能力：**前置主角覆盖硬门槛**与**炼本主角镜头规划**。

#### 新增

1. **前置主角覆盖检查（硬门槛）**
   - 自动识别全剧唯一主角，单主角，不做双主角设定。
   - 新增 `tools/protagonist_profile.py`：从 `work/source/epNN.md` 的 `人物：` 行、台词说话人、出场集数与中英别名自动识别主角，输出 `work/meta/protagonist.json`。
   - 新增 `tools/preflight_protagonist_check.py`：统计每集主角场次占比、台词占比、动作占比与逐场 `scene_map`，输出 `work/preflight/protagonist.json`。
   - `NO_PROTAGONIST`（主角完全未出场且无台词）或 `LOW_PROTAGONIST`（场次占比 <40% 或台词占比 <20%）的集标记为 `blocked`，**不进入炼本**。
   - `BORDERLINE`（场次 <55% / 台词 <35% / 覆盖分 <0.45）只提示，不阻断。
   - blocked 只在前置阶段判定；已有非空 `work/draft/epNN.md` 或已进入炼本状态的集不回判。

2. **炼本主角镜头规划（P/R/N）**
   - 新增 `参考资料/炼本细则/protagonist-shot-design.md`：定义主角镜 `P`、主角关系镜 `R`、非主角镜 `N`，以及 POV、过肩、前景、框内观察、手部/物件插入、VO/OS、反应切、因果回切、声音桥等合法关联方式。
   - 每集先做镜头规划，再写正文；规划写入 `work/report/epNN.json` 的 `shot_plan`。
   - 默认目标：主角关联镜 `(P+R)/total` ≥70%，主角本人镜 `P/total` ≥35%，纯 `N` ≤30%，连续 `N` ≤2，连续配角互动 `N` ≤2；有主角在场的场次至少 1 个 P/R。
   - 新增根目录 `shot-profile.json`，集中配置主角覆盖门槛、镜头比例、`warn` / `enforce` 模式。
   - `tools/check_ep.py`、`tools/final_audit.py` 增加主角镜头机检；`generate_qc_report.py` 增加“主角覆盖与未进入炼本”和“主角镜头规划”两节。

#### 行为变化

- `/前置检查` 末尾新增主角覆盖检查与 blocked 集清单。
- `/炼剧本` 不再重新判断主角覆盖，只读取前置 blocked 结果；blocked 集跳过，存在 blocked 集时使用 `--allow-partial` 生成部分成品，并在质检报告与总修改说明中列出。
- blocked 集不替换源 docx 原文；成品 Markdown 不包含 blocked 集。
- 主角镜头比例默认 `mode: "warn"`（只报告）；建议先跑 3—5 集校准，再改为 `"enforce"` 作为硬失败。前置 blocked 始终为硬门槛。

### English

This release adds two capabilities to the 1.0 narration-drama refinement workflow: a **hard preflight protagonist-coverage gate** and **protagonist-aware shot planning** during refinement.

#### Added

1. **Preflight protagonist-coverage gate (hard gate)**
   - Automatically detects a single series protagonist. Dual-protagonist configuration is intentionally not supported.
   - New `tools/protagonist_profile.py`: detects the protagonist from `人物：` lines, dialogue speakers, episode coverage, and CN/EN aliases in `work/source/epNN.md`; writes `work/meta/protagonist.json`.
   - New `tools/preflight_protagonist_check.py`: computes per-episode protagonist scene ratio, dialogue ratio, action ratio, and a per-scene `scene_map`; writes `work/preflight/protagonist.json`.
   - Episodes marked `NO_PROTAGONIST` (no appearance and no dialogue) or `LOW_PROTAGONIST` (scene ratio <40% or dialogue ratio <20%) are set to `blocked` and **do not enter refinement**.
   - `BORDERLINE` (scene ratio <55% / dialogue ratio <35% / coverage score <0.45) is reported but not blocked.
   - Blocking is decided only during preflight. Episodes with a non-empty `work/draft/epNN.md` or an existing refinement status are not re-judged.

2. **Protagonist-aware shot planning (P/R/N)**
   - New `参考资料/炼本细则/protagonist-shot-design.md`: defines protagonist shots (`P`), protagonist-relation shots (`R`), and non-protagonist shots (`N`), plus legal anchors such as POV, over-the-shoulder, foreground, frame observation, hand/prop insert, VO/OS, reaction cut, causal cutback, and sound bridge.
   - Each episode plans shots before writing the draft; the plan is stored in `shot_plan` inside `work/report/epNN.json`.
   - Default targets: protagonist-related shots `(P+R)/total` ≥70%, protagonist-present shots `P/total` ≥35%, pure `N` ≤30%, consecutive `N` ≤2, consecutive supporting-interaction `N` ≤2; every scene with the protagonist present must contain at least one P/R shot.
   - New root `shot-profile.json` for coverage thresholds, shot ratios, and `warn` / `enforce` mode.
   - `tools/check_ep.py` and `tools/final_audit.py` now validate the shot plan; `generate_qc_report.py` adds “Protagonist Coverage / Not Refined” and “Protagonist Shot Planning” sections.

#### Behavior changes

- `/前置检查` now runs the protagonist-coverage check and reports blocked episodes.
- `/炼剧本` no longer re-evaluates protagonist coverage; it only consumes the preflight `blocked` result. Blocked episodes are skipped. When blocked episodes exist, partial output is produced with `--allow-partial`, and blocked episodes are listed in the QC report and production summary.
- Blocked episodes are not replaced in the output docx; the merged Markdown excludes them.
- Shot-ratio validation defaults to `mode: "warn"` (report only). Run 3–5 episodes to calibrate, then switch to `"enforce"` for hard failures. The preflight blocked gate is always hard.

#### Upgrade notes

- For existing projects, rerun `/前置检查` once to generate `work/meta/protagonist.json` and `work/preflight/protagonist.json`.
- If the auto-detected protagonist is wrong, correct `work/meta/protagonist.json` and rerun the coverage check. Dual protagonists are not supported in this release.
- To disable shot planning, set `enabled` to `false` in `shot-profile.json`. Disabling the preflight blocked gate is not recommended.
