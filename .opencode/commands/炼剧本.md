你是编排者。前置条件：`work/source/` 已有 /前置检查 生成的分集优化存档。

## 阶段 0：前置校验

1. 检查 `work/source/ep*.md` 是否存在；无 → 提示“请先运行 /前置检查 完成前置检查与优化存档”，停止。
2. 若 `work/meta/ep_index.json` 或 `work/meta/progress.json` 缺失，运行 `python tools/assemble_source.py --rebuild` 从现有 `work/source` 重建索引与进度。
3. 读取 `work/meta/progress.json`，列出所有状态不是 `passed` / `passed-with-issues` 的集号（两位数 epNN）作为待炼集；全部已通过则跳到阶段 2。

## 阶段 1：并发炼稿与校验（每波最多 20 集）

4. 每波最多 20 集，在【同一条消息】并列发出 director task；每个调用：
   - `agent`: `director`
   - `description`: `炼稿 EPnn`
   - `prompt`: `处理第 NN 集。先完整读取 .opencode/agents/director.md 并严格执行其中全部规范（含必读文件清单，以及“每句台词括号内必须填写可表演的细致情绪或神态”硬规则；括号提示须含声音/气息/情绪状态 + 至少一个可拍的面部、眼部、下颌、喉部或手部细节，情绪落点句 2—3 个可见细节；连续动作与姿态余波写入 △，不得把动作段塞进括号），完成 work/draft/epNN.md、work/report/epNN.json、work/report/epNN_production_notes.md 写盘。只回一行状态。`
5. 每波完成后运行 `python tools/check_ep.py --eps <本波集号,逗号分隔>`。
6. 校验 FAILED 的集：读取 `work/report/check_epNN.json` 的失败原因，写入 `work/meta/retry_epNN.txt`；下一波把重试要求追加到 prompt 重发：
   `处理第 NN 集（重试）。先读 work/meta/retry_epNN.txt 与现有 work/draft/epNN.md，逐项修复其中列出的全部问题后重写整集；同时完整执行 .opencode/agents/director.md 全部规范。只回一行状态。`
   单集最多重试 2 次。不得跳过校验。
7. 重试超限集：运行 `python tools/check_ep.py --eps <集号> --allow-issue-pass` 降级通过（自动生成 `work/report/epNN_issue.md`，进度标记 `passed-with-issues`）。
8. 重复直到全部集通过（`passed` 或 `passed-with-issues`）。

## 阶段 2：合并、回写与终检

9. 运行 `python tools/merge.py`（全部通过时无需 `--allow-partial`）。
10. 运行 `python tools/writeback_docx.py`（回写成品 docx，保留源文档排版；输出锁定错误提示关闭 Word/WPS 后重跑）。
11. 运行 `python tools/final_audit.py`。
12. 运行 `python tools/generate_summary.py`（生成 `work/report/production_summary.md` 总修改优化说明）。
13. 运行 `python tools/generate_qc_report.py`，生成 `output/<剧本名>_质检报告.md` 与 `.docx`：报告有无较大剧情修改（逻辑修复明细、场景统一、动作丰富统计）、各集在全部阶段（前置/炼本）的台词变动核查结果，以及动作/对白密度检测与处理记录（△/台词比、最长 △ 段、最长连续对白段、△ 检测与对白检测命中、合并前→后 △ 条数与 △ 合并明细）。
14. 最终报告必须包含：通过 / 降级通过 / 未通过集号；成品 Markdown 与 docx 路径（`output/`）；质检报告路径（`output/<剧本名>_质检报告.md/.docx`）；总修改优化说明路径（`work/report/production_summary.md`）；各集制作说明路径列表（`work/report/epNN_production_notes.md`）；若有 `passed-with-issues` 集则单独列出并附对应 `epNN_issue.md` 路径。

约束：不要把 draft 正文读进主上下文；不要修改 `参考资料/`；worker 只回一行状态；每波 task 调用必须在同一条消息并列发出以保证并发。
